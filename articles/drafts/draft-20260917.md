# 🛠️ [实测] NeoHorse实测：首个Agent-Native模型，把"会调用工具"烧进权重里

> 📂 合集：**🛠️ 工具实测** | 模板：tool-review.md
> 发布日期：2026-09-17（周四）
> 适用对象：关注 Agent、想搞清"原生 Agent 模型"和普通聊天模型差在哪的人

---

**上周我把一个"查邮件、看目录、再排期"的任务丢给一个 4B 小模型。它找到了工作目录里的文件，却漏读了一封写着最新依赖约束的邮件，按过时信息写了计划，还把文件写到了错误位置。**

这不是我编的翻车故事，是基元律动技术报告里的真实案例。**普通模型会聊天、会写代码，但不等于它会"干活"——干活要会用工具、会看反馈、会改错。**

9 月 8 日，基元律动（TokenRhythm）联合无问芯穹，和清华大学、北京大学、阿里巴巴等机构，推出了他们称为**首个 Agent-Native 模型**的 NeoHorse-1。一句话结论：**它不是再做一个外挂 Agent 框架，而是把"调用工具、接收反馈、修正错误"的经验，直接后训练进 4B / 9B 的权重里。**

> ⚠️ 声明：本文基于中国证券报、雷峰网、arXiv 技术报告（2609.08183）和 Hugging Face 模型卡整理，我未做账号级长测。关键数字均标注出处。

---

## 先搞清：Agent-Native 到底新在哪

市面上大部分"AI Agent"，本质是**外挂**：底座模型还是聊天模型，外面再套一层工作流——路由、工具、记忆、重试，全写在代码里。

NeoHorse 走的是另一条路：**让模型自己长出 Agent 能力。**

底座是阿里开源的 **Qwen3.5-4B** 和 **Qwen3.5-9B**。基元律动此前开源过一套 Routing Harness（路由套件）叫 **OpenSquilla**，用来在执行任务时给不同模型分活。这次他们把 Harness 跑出来的**执行轨迹**——能力需求预测、路由选择、模型响应、工具调用、环境反馈——当成后训练语料，喂回模型。

无问芯穹负责训练和推理的底层 Infra；清华、北大团队参与算法和训练方法。公司创始人是前华为诺亚方舟实验室主任、盘古大模型负责人王云鹤。

**说白了：以前是"聪明的嘴 + 外面的手"；NeoHorse 想把手当成肌肉，长在模型身上。**

他们还给这条路起了个更大的名字：**Harness 驱动的递归自我改进（RSI）**——执行留下轨迹，评测暴露短板，训练跟着改，更新后的模型再回到 Harness。技术报告写得很克制：这只是**单轮工程验证**，不是已经实现了"模型自己无限进化"。

---

## 上手门槛：开源能下，但不是"点一下就能用"

按实测文的习惯，先看门槛：

- **权重**：Hugging Face 上已放 **NeoHorse-1-4B**、**NeoHorse-1-9B**，Apache-2.0，可商用。
- **形态**：纯文本因果语言模型，**不含视觉权重**。上下文原生 **262,144 Token**，可扩展到约 **101 万 Token**。
- **部署**：官方示例是 **SGLang 0.5.17** 或 **vLLM**，走 OpenAI 兼容接口，工具调用解析器用 `qwen3_coder`。
- **成本**：权重免费。算力你自己出。4B 比 9B 友好，但 26 万上下文按满开，显存照样会炸，需要按机器把 `--max-model-len` 砍下来。

**对普通人：这不是豆包、Kimi 那种网页聊天机器人。** 你要会下模型、起服务，或者等别人把它接到现成的 Agent 套件里。现在它更像给开发者和研究者的"底座零件"。

> ⚠️ 一个坑先放这儿：模型卡写得很清楚——这次发的是**文本推理权重**，别指望它看图、看屏幕。Agent-Native ≠ 多模态，更 ≠ 已经替你装好了浏览器和邮箱。

## 核心实测：公开基准里，它到底强在哪

我把 Hugging Face 模型卡上的 4B 对照表拆开看。评测协议写的是 SGLang v0.5.17、开启 thinking 模式。数字是官方自报，未独立复现。

### 点 1：同样 4B，后训练把均分从 58.94 拉到 64.87

十项基准的宏平均：Qwen3.5-4B 是 **58.94**，NeoHorse-1-4B 是 **64.87**（**+5.93**）。9B 线是 65.60 → 69.04（+3.44）。

雷峰网转述报告时还写了一句更刺的：**4B 级里 NeoHorse 未加权平均最高，并在五项基准上超过 Qwen3.5-9B 底座。** 小模型靠"干活轨迹"后训练，摸到大一号底座的边——这才是这条路线想证明的事。

### 点 2：涨分涨在"能跑流程"的题上，不是背课文

4B 对比 Qwen3.5-4B，涨得最狠的几项（模型卡）：

| 基准 | 底座 4B | NeoHorse-1-4B | 变化 |
|------|---------|---------------|------|
| VitaBench | 21.50 | 32.00 | +10.50 |
| WorkBuddy Bench | 24.62 | 34.41 | +9.79 |
| HumanEval | 87.20 | 96.95 | +9.75 |
| QwenClawBench | 38.47 | 44.68 | +6.21 |
| PinchBench | 71.19 | 77.33 | +6.14 |

VitaBench、WorkBuddy、QwenClaw 这类，测的是**工具、环境、多步执行**。HumanEval 涨了近 10 分，说明代码也吃到了轨迹数据的红利。

BFCL v4 只 +0.77，几乎没动——不是所有"工具题"都被同一套后训练打穿。

### 点 3：它不是 4B 赛道的全能王

同一张表里，**指令遵循 IFBench：星火 X2.5-4B 73.33，NeoHorse 65.33**；LiveCodeBench v6 南贝 4.2-3B 报了 72.50（带星号，来自对方官方），NeoHorse 是 59.43。

雷峰网的判断和报告一致：**改善主要集中在流程清晰、反馈可观察、结果可验证的任务上；更大模型在复杂状态维护、长程调试和失败恢复上仍有优势。**

**一句话：NeoHorse 赢在"会按环境反馈改"，不赢在"什么都会"。**

## 惊喜和槽点，摊开说

👍 做得好的：

- **问题定义清楚。** 不跟旗舰拼聊天，专攻 Agent 后训练，和本周一写的星火 X2.5-4B、本月的 Manus，形成三条不同的"让 AI 干活"路线。
- **数据闭环写得很工程。** 去重、评测去污染、结构校验、六维语义评估、按 Scene/Goal/Outcome 打标，再按路由信号做三阶段课程学习 + 在策略蒸馏。这不是发个"Agent 微调版"糊弄人。
- **开源态度干净。** Apache-2.0，保留通义千问上游版权声明，部署示例可直接抄。

👎 需要改进的：

- **RSI 目前只有一轮。** 技术报告自己把话说死了：这是原型，下一轮迭代才是"递归"真正开始的地方。别被标题里的 Self-Improvement 带跑。
- **普通用户几乎无产品入口。** 没有网页 Demo、没有一键 App，和"小微""豆包"不在一个使用层。
- **对比对象是开源 4B/9B，不是 GPT-6 Astra、Claude Fable。** 别拿它去打旗舰电脑操作。量级不同。

---

## 适合谁用，不适合谁

- **适合**：已经在用 vLLM / SGLang、想给开源小模型补工具调用能力的开发者；做 Agent 研究、想复现"轨迹 → 后训练"的人。
- **不适合**：只想网页里让 AI 订机票、写周报的人——你更该用 Manus、扣子，或直接用 DeepSeek / 通义的官方 Agent 功能。
- **免费版够用吗**：权重免费。贵的是你的 GPU。4B 能起服务再谈；9B 当研究用更合适。

**如果你上周刚看完 Manus 那篇：Manus 卖的是"能用的产品"；NeoHorse 卖的是"能训的方法"。一个是餐厅，一个是厨子学校。**

---

**一句话总结：NeoHorse 没有重新发明 Agent，它证明了一件更扎实的事——把真实干活的轨迹烧进小模型，4B 真的能在"会用工具"上逼近 9B 底座。现在它还是实验室和开源仓库里的原型，不是你手机上的下一个超级助理。**
