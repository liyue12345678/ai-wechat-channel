# 🎓 [教程] 用AI做一份投资人看了想约见的商业计划书：从市场分析到财务预测全流程

> 📂 合集：**🎓 手把手教程** | 模板：tutorial.md
> 发布日期：2026-07-22（周三）
> 适用对象：创业者、想做副业的人、需要写BP的职场人

---

**先说清楚：AI不能替你"想出好的商业模式"——但它可以帮你把一个模糊的想法，变成一份结构完整、逻辑清晰、看起来像模像样的商业计划书。**

我去年帮朋友看过几份BP，最普遍的问题不是"想法不好"，而是"说不清楚"——市场有多大？竞品有谁？钱花在哪？很多创始人脑子里有答案，但写到纸上就散了。

AI最适合做的就是这个：把你脑子里那些碎片化的想法，组织成投资人想看的格式。

这篇文章覆盖商业计划书的全部核心模块，每一步都给出了可直接复制的提示词。

⏱ 总耗时：2-3小时（其中80%是你在思考和决策，AI只是帮你"写出来"）
💰 花费：¥0（全部用免费工具）

## 二、全流程概览

写商业计划书分为6个模块，AI在每个模块扮演不同角色：

| 阶段 | AI的角色 | 你要做的事 | 耗时 |
|------|---------|-----------|------|
| 1. 项目定位 | 把模糊想法变成一句话价值主张 | 想清楚你到底要做什么 | 15min |
| 2. 市场分析 | 搜数据+估算市场规模 | 判断数据是否合理 | 30min |
| 3. 竞争分析 | 找竞品+做对比矩阵 | 确认竞品信息准确 | 30min |
| 4. 商业模式 | 梳理收入来源和成本结构 | 判断商业模式是否成立 | 20min |
| 5. 财务预测 | 做简单财务模型 | 调整参数看不同情况 | 20min |
| 6. 整合成BP | 把所有模块组装成完整文档 | 通读+调逻辑+改措辞 | 30min |

**核心原则：AI是你的"分析师+文案"，不是你的"大脑"。商业模式的对错、市场判断的准确与否——这些只有你能决定。**

## 三、阶段一：项目定位 — 一句话说清楚你要做什么

这是整个BP最重要的部分。投资人看BP平均只花3分钟——前30秒决定要不要继续看。如果你的第一页不能让人"哦，这个有意思"，后面写得再好也没用。

### 步骤1：用AI帮你提炼"一句话价值主张"

把你脑子里关于这个项目的所有想法——不管多乱——先全部打出来。然后丢给AI：

```
我正在筹备一个创业项目，以下是我目前的想法（比较零散，帮我梳理一下）：

[在这里把你所有的想法倒出来，不要在意格式。比如：
- 我想做一个帮小商家管理库存的SaaS工具
- 现在小店老板都用Excel记账，经常搞错
- 我的优势是我以前开过店，知道他们痛点
- 可能先从餐饮行业切入
- 等等……]

请帮我做以下事情：

1. 用一句话描述这个项目的价值主张（格式："我们帮助[目标用户]解决[什么问题]，通过[什么方式]，让他们获得[什么价值]"）

2. 列出这个项目的3个核心假设（最不确定但最关键的事）：
   - 假设1：
   - 假设2：
   - 假设3：
   
3. 提炼一个30秒的"电梯演讲"版本，让完全不了解这个行业的人也能听懂。

直接、清晰、不要套话。"颠覆""赋能"这种词少用。
```

### 步骤2：红队演练——让AI挑战你的想法

在你深入写BP之前，做一个"红队演练"——让AI扮演挑剔的投资人，挑战你的每一个假设。这一步能帮你提前发现逻辑漏洞：

```
现在请你扮演一个经验丰富的早期投资人。你已经看过几百个创业项目，对"听起来很美但经不起推敲"的项目有敏锐的直觉。

请针对我刚才描述的项目，从以下角度提出尖锐的质疑：

1. 需求真伪：你怎么确定用户真的需要这个？（不是"他们说自己需要"，是"他们愿意为此付费"）
2. 市场时机：为什么是现在？为什么过去没人做成？
3. 竞争壁垒：如果腾讯/字节/阿里明天决定做这个，你凭什么活下来？
4. 单位经济：这笔生意在"每一单"上到底赚不赚钱？
5. 团队：为什么是你？你和这件事的匹配度在哪里？

每个质疑请具体，不要泛泛地问"你们的核心竞争力是什么"——直接说出你看到的风险点。
```

**这可能是整篇教程里最有价值的步骤。** 如果你被AI的问题问住了——不要慌，这说明你需要在这个点上想得更清楚。宁可现在被AI问住，也不要见到投资人之后被问住。

## 四、阶段二：市场分析 — 用数据证明"这个市场值得做"

投资人最反感的一句话："这是一个万亿级的市场。"——太空泛了。你需要回答三个具体问题：你的目标市场到底多大？在增长还是萎缩？你打算切哪一块？

### 步骤1：搜集市场数据

用秘塔AI搜索或Kimi探索版：

```
请帮我搜索以下信息，用于撰写商业计划书的市场分析部分：

行业：[你的行业，如"中国餐饮SaaS市场"]
时间范围：2024-2026年最新数据

请搜索并整理：
1. 行业市场规模（总规模 + 你目标细分领域的规模）
2. 近3年的增长率（是上升还是下降）
3. 3-5个关键行业趋势（政策、技术、消费习惯变化）
4. 这个行业的集中度（是分散的"蚂蚁市场"还是头部的"寡头市场"）

每个数据请标注来源。如果不同来源的数据有矛盾，请指出并给出你的判断。
```

### 步骤2：做市场规模估算（TAM/SAM/SOM）

搜完外部数据后，让AI帮你做三层市场估算：

```
基于以上搜索到的市场数据，帮我计算这个项目的TAM/SAM/SOM：

- TAM（总潜在市场）：整个[行业/品类]在中国的总市场规模
- SAM（可服务市场）：我们的产品/服务能触及的那部分市场的规模
- SOM（可获得市场）：在SAM中，基于我们目前的资源和策略，初期能实际获取的市场份额

请用以下格式呈现：

| 层级 | 定义 | 规模（人民币） | 计算逻辑 |
|------|------|--------------|---------|
| TAM | 中国XX行业总规模 | XX亿 | 来源：XX报告 |
| SAM | 其中XX细分领域 | XX亿 | TAM × XX%（细分占比） |
| SOM | 初期目标 | XX万 | SAM × XX%（初期渗透率假设） |

我的产品定价是[XX元/月/用户]，目标用户群体是[描述]，请结合这些信息调整估算。
```

> ⚠️ **重要提醒：** AI估算的市场规模是"合理推测"，不是"准确数据"。你必须自己判断这些数字是否合理。特别是SOM——宁可低估，不要吹牛。投资人一眼就能看出数字是拍脑袋还是认真算过的。

## 五、阶段三：竞争分析 — 说清楚"凭什么不是别人"

### 步骤1：找竞品

```
请帮我做一个竞品分析，用于商业计划书的"竞争格局"部分。

我的项目是：[一句话描述]

请搜索并分析以下内容：

1. 直接竞品（做同样事情的公司/产品）：列出3-5个
2. 间接竞品（用不同方式解决同一问题的）：列出3-5个
3. 潜在竞品（目前没做但随时可能进入的巨头）：列出2-3个

对每个竞品，请整理：
- 公司/产品名称
- 一句话定位
- 融资情况/规模（如果能搜到）
- 核心优势（他们做得好的）
- 核心劣势（他们做得不好的——这是我们切入的机会）
```

### 步骤2：做竞争矩阵

搜完竞品信息后，做一张对比表：

```
基于上述竞品分析，帮我制作一张竞争定位矩阵：

请选择两个最关键的竞争维度（比如：X轴="产品功能完整度"，Y轴="价格/性价比"），
把我们的项目和主要竞品放在这张矩阵上，并标注每个玩家的位置。

然后用文字说明：
1. 我们在矩阵中的位置，和最近的竞品之间的差异是什么
2. 我们的"护城河"是什么（为什么竞品不能轻易复制）：
   - 技术壁垒？
   - 网络效应？
   - 品牌/口碑？
   - 独家资源/合作关系？
   - 先发优势/数据积累？
   - （如果上面的都没有，请诚实地说"目前没有明显壁垒"——然后想清楚怎么建立）
```

**一个残酷的事实：** 如果你的竞品分析写完后，发现自己的项目在矩阵里没有任何差异化的位置——每个维度都有人在做了，而且做得比你好——那就要重新思考这个项目了。AI可以帮你写出漂亮的竞品分析，但改变不了"你的项目有没有差异化"这个事实。

## 六、阶段四：商业模式 — 钱从哪来，花到哪去

这是投资人最关心的部分。如果前面三个模块是"听上去不错"，这个模块是"能赚钱吗"。

### 提示词：商业模式画布

```
基于我的项目信息，帮我梳理商业模式：

项目：[一句话描述]
目标用户：[谁会用]
核心价值：[帮用户解决了什么问题]

请按以下结构输出：

1. 收入来源（钱从哪来）：
   - 主要收入来源：XXX（预计占比XX%）
   - 次要收入来源：XXX（预计占比XX%）
   - 未来可能的收入来源：XXX
   
   请具体到定价策略：[订阅制/按次收费/抽佣/广告/增值服务]
   定价参考：[竞品A收费XX，竞品B收费XX，我们收费XX，理由：XXX]

2. 成本结构（钱花到哪去）：
   - 固定成本：人力（多少人×多少钱）、服务器/基础设施、办公场地
   - 可变成本：获客成本（CAC）、服务交付成本、支付手续费
   - 请按"初期（前12个月）"分月估算

3. 关键指标（怎么算"做成了"）：
   - 用户获取成本（CAC）：获取一个付费用户花多少钱
   - 用户终身价值（LTV）：一个用户在整个生命周期内贡献多少收入
   - LTV/CAC比值：理想情况应 > 3
   - 盈亏平衡点：大概需要多少用户/多长时间

4. 增长路径：
   - 前100个用户怎么来？
   - 前1000个用户怎么来？
   - 10000个用户怎么来？
   （不要写"通过口碑传播"——那叫希望，不叫策略）
```

**如果你自己也不知道这些数字该填多少——没关系。让AI帮你做"假设"，然后你做"判断"。** 比如AI可能假设一个付费用户的获客成本是50元——你根据自己的行业经验判断这个数字偏高还是偏低，然后调整。这个迭代过程本身就是在帮你理清商业模式。

## 七、阶段五：财务预测 — 让数字说话

财务预测是大部分非金融背景创业者最头疼的部分。好消息是：AI做简单的财务模型非常擅长。

### 步骤1：收入预测

```
基于以下假设，帮我做一个简单的三年收入预测：

项目：[一句话]
定价：[XX元/月或XX元/次]
用户增长假设：
- 第1年：前6个月[XX个新用户/月]，后6个月[XX个新用户/月]
- 第2年：[增长XX%]
- 第3年：[增长XX%]
用户流失率假设：[X%/月]（如果不知道，先用行业平均5%）

请输出：
1. 第1-3年每年的用户数（总用户、付费用户、新增用户）
2. 第1-3年每年的收入（总收入、拆分到各收入来源）
3. 如果有多个收入来源，请分别计算

格式：表格
```

### 步骤2：成本预测

```
基于以下信息，帮我做一个三年的成本预测：

团队规模计划：
- 第1年：[技术X人 + 运营X人 + ...] 共X人
- 第2年：团队增至X人
- 第3年：团队增至X人

人均成本：[XX万/年]（含工资+社保+福利，按你所在城市估算）

其他成本假设：
- 服务器/基础设施：[XX万/年]
- 市场营销：[收入的XX%]
- 其他杂项：[XX万/年]

请输出每年的成本明细表和总成本。
```

### 步骤3：合并成财务简表

```
请将以上收入和成本预测合并，输出：

1. 简化版损益表（第1-3年）：
   | 项目 | 第1年 | 第2年 | 第3年 |
   |------|-------|-------|-------|
   | 总收入 | | | |
   | 总成本 | | | |
   | 毛利润 | | | |
   | 净利润 | | | |

2. 关键财务指标：
   - 毛利率
   - 净利率
   - 盈亏平衡月份（预计第几个月收入覆盖成本）
   - 现金流转正时间点

3. 敏感性分析（重要！）：
   - 乐观情况：用户增长比预期快50% → 数据会怎样？
   - 保守情况：用户增长比预期慢30% → 数据会怎样？
   - 最差情况：增长不及预期 + 一个季度收入为零 → 现金流能撑多久？
```

> 💡 **技巧：** 财务预测的核心不是"预测得准不准"（肯定不准），而是"展示你的思考逻辑"。投资人看财务预测的时候，在看三件事：①你的假设是否合理，②你对自己的商业模式理解到什么程度，③你对风险的意识有多强。**一份有"敏感性分析"的BP，天然比没有的看起来专业很多。**

## 八、阶段六：整合成完整BP文档

前面的所有模块——定位、市场、竞争、商业模式、财务——都已经准备好了。最后一步是把它们整合成一份完整的、格式统一的商业计划书。

### 提示词：生成完整BP

```
请将我们之前讨论的所有内容，整合成一份完整的商业计划书。

结构要求（按以下顺序）：

封面页：项目名称 + 一句话价值主张 + 你的名字/团队 + 日期

1. 执行摘要（1页）
   - 这是整个BP最重要的部分：投资人读完这一页就应该能决定要不要继续看
   - 包含：问题、解决方案、市场机会、商业模式简述、核心数据、团队亮点、融资需求

2. 项目定位与价值主张（0.5页）
   - 我们在解决什么问题？为什么这个问题值得解决？

3. 市场分析（1-2页）
   - 市场规模（TAM/SAM/SOM）、增长趋势、市场驱动因素

4. 竞争分析（1页）
   - 竞争格局图、竞品对比表、我们的差异化优势

5. 产品与服务（1页）
   - 产品核心功能、用户流程、当前状态（已上线/内测/开发中）

6. 商业模式（1页）
   - 收入来源、定价策略、单位经济模型

7. 增长策略（0.5页）
   - 用户获取路径、关键渠道、增长飞轮

8. 团队介绍（0.5页）
   - 核心成员背景、为什么这个团队能做这件事

9. 财务预测（1-2页）
   - 三年收入/成本预测、关键指标、敏感性分析

10. 融资需求（0.5页）
    - 本轮融资金额、估值预期、资金用途分配、预计达成里程碑

格式要求：
- 总篇幅控制在10-15页
- 每页标题清晰，能用一句话总结"这页在说什么"
- 数据用表格，不要长篇大论的数字
- 少用形容词（"巨大的""颠覆性的""革命性的"），多用具体数字
- 适合导出为PDF格式
```

## 九、三个让BP脱颖而出的技巧

### 技巧1：第一页定生死

投资人一天看10-20份BP。如果你的执行摘要不能在30秒内说清楚"什么问题、怎么解决、为什么是你、市场多大、要多少钱"——剩下的内容大概率不会被读到。

**不要犯的错误：** 执行摘要写成了"公司简介"——从公司成立背景开始讲起。投资人不关心你的心路历程，他们关心"这个机会值不值得花时间了解"。

### 技巧2：每一页都要回答"所以呢？"

写完每一页之后，问自己这个问题。如果答案是"没什么特别的"——或者更糟，"不知道"——那这页需要重写。

举例：
- "我们的目标市场是100亿。" — 所以呢？
- "我们的目标市场是100亿，其中XX细分领域占30亿，且年增长20%，目前还没有明确的领头羊。我们的产品针对这个空白。" — 这才是投资人有兴趣读下去的。

### 技巧3：用AI做"投资人模拟"

在真正见投资人之前，把BP丢给AI做最后一次"模拟演练"：

```
请扮演一个看过500+份BP的种子轮投资人。

通读下面这份商业计划书——你只有3分钟来决定要不要约创始人面谈。

3分钟后，请告诉我：
1. 你的第一印象是什么？（是"有意思，想聊"还是"下一个"）
2. 这份BP最有说服力的3个点是什么？
3. 最让你犹豫/质疑的3个点是什么？
4. 如果创始人站在你面前，你最想问的3个问题是什么？

请冷酷、直接，不要为了鼓励我而说好话。如果项目有问题，直接指出来比委婉更对我有帮助。

[粘贴你的BP]
```

## 十一、一个最重要的提醒

**商业计划书是手段，不是目的。**

写BP的目的是两个：①帮你自己把思路理清楚（可能比"拿到投资"更重要）；②让投资人愿意和你面谈（不是直接打钱——没有人看完BP就打钱的）。

一份好的BP的价值不在于"文笔多好"，而在于——当你被问到任何一个模块的问题时，你能给出比BP上写的更深入、更有信心的回答。因为AI帮你写了初稿，而你在这个基础上想得更深了。

**不要犯的错误：AI生成了BP之后，你自己没读、没改、没深入想过——然后投资人一个追问就把你问懵了。** 那一瞬间，BP写得再漂亮也没用。
