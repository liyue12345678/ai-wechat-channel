## 一、先搞清楚：AI工具到底有几类开销？

在列价格之前，先把工具分类——不同类别的东西放一起比价格没意义。

| 类别 | 典型产品 | 你用它干什么 |
|------|---------|------------|
| **大模型/聊天** | ChatGPT, Claude, DeepSeek, 豆包, Kimi, 通义千问 | 写作、翻译、编程、分析、问答 |
| **AI搜索** | Perplexity, Kimi搜索, 秘塔, 天工 | 调研、查资料、验证信息 |
| **AI绘画** | Midjourney, DALL·E, SD, 文心一格 | 配图、封面、海报、设计灵感 |
| **AI视频** | Runway, Pika, 可灵, Sora | 视频生成、剪辑、特效 |
| **AI编程** | Cursor, Copilot, Windsurf, 通义灵码 | 写代码、debug、代码审查 |
| **AI音乐/语音** | Suno, ElevenLabs, 剪映配音 | 背景音乐、配音、播客 |
| **AI办公** | Notion AI, Gamma, 各类AI PPT工具 | 文档、PPT、会议纪要 |

一个普通用户不会每类都订——**通常只用到2-3类**。下面的分级，按你最可能实际花钱的方式排列。

## 二、🆓 第一档：一分钱不花（免费方案）

先说好消息：**2026年，免费AI工具的质量已经超过2024年的付费工具。** 如果你只是日常写作、查资料、偶尔做图，完全不用花一分钱。

### 免费党最优组合

| 用途 | 免费首选项 | 免费备选 | 够用吗？ |
|------|-----------|---------|---------|
| 写作/聊天/分析 | DeepSeek V4 | Kimi, 豆包 | ✅ 完全够 |
| 联网搜索 | Kimi（深度研究） | 秘塔搜索 | ✅ 完全够 |
| 代码辅助 | 通义灵码 | Codeium | ✅ 日常够 |
| AI绘画（少量） | DALL·E（ChatGPT免费版每月几张） | 通义万相 | ⚠️ 限次数 |
| AI视频 | 可灵（免费额度） | 剪映AI功能 | ⚠️ 有水印 |
| 文档/PPT | Gamma（免费版） | 腾讯文档AI | ⚠️ 有次数限制 |

**这套组合的总花费：¥0/月。**

### 免费方案的真实体验

我在"DeepSeek V4用了两个月"那篇里写过——DeepSeek免费版的质量，在写作、翻译、数据分析这些日常场景里，和ChatGPT付费版的差距已经很小了。唯一的短板是它写出来的东西"人味"稍弱，但这个问题用一段润色提示词就能解决。

**免费方案适合谁：**
- 学生（作业、论文辅助）
- 偶尔用AI的上班族（周报、邮件、简单文档）
- 还在观望、不确定要不要为AI付费的人

**免费方案的限制：**
- 高峰期可能排队（DeepSeek偶尔慢）
- 高级功能受限（DALL·E免费版只能生成低分辨率图）
- 没有优先客服支持
- 绘画和视频类工具限制最明显

这一档是"AI全面武装"级别。**除非你是全职自媒体、独立开发者、设计工作室，否则这个预算不太划算。**

这个价格差不多是一部中端手机的月供。说实话，除非你的工作流真的需要这么多工具同时在线，否则一定是有重叠浪费的。

### 怎么砍？

检查你的订阅清单，问自己三个问题：

1. **有没有功能性重叠？** 比如同时订了ChatGPT Plus和Claude Pro——你最后一个星期分别用了它们几次？
2. **有没有"订了没怎么用"的？** 上个月给Midjourney交了$30，实际出图不到20张。
3. **有没有免费平替？** 你可能不知道DeepSeek现在能直接处理你80%的工作。

**砍掉一个浪费的订阅，一年省下来的钱够买一台新手机。**

## 六、三种典型用户的最优方案

不搞"一刀切"推荐。按你的实际情况对号入座：

### 👤 类型一：轻度用户（每天<30分钟）
```
推荐方案：全免费
DeepSeek V4 + Kimi搜索 + 通义灵码（可选）
花费：¥0/月
覆盖：日常写作、查资料、简单分析
```
> 别被FOMO绑架。如果你每周用AI不到3小时，付费版的额外功能你根本用不到。

### 👤 类型二：中度用户（每天1-2小时，用AI辅助工作）
```
推荐方案：免费主力 + 一个付费工具
DeepSeek V4（免费） + Claude Pro 或 ChatGPT Plus（$20/月）
花费：$20/月（约¥140）
覆盖：写作、分析、编程、学习
```
> 这是性价比最高的区间。$20买的是"高峰期不排队+高级功能+画图"，不是买"AI更强"——免费版已经很强了。

### 👤 类型三：重度用户（每天2小时+，用AI直接产出）
```
推荐方案：核心付费工具2-3个
ChatGPT Plus 或 Claude Pro（$20）+ Midjourney Standard（$30）或 Runway（$15）
花费：$35-65/月（约¥245-455）
覆盖：写稿 + 配图 + 视频全流程
```
> 到这个级别，AI是你的生产工具，不是玩具。$50/月产生的价值应该远超这个数——如果不是，说明你没用对。

## 七、一个意外的发现

在整理这份盘点的时候，我发现了一个有意思的现象：

**国内AI工具几乎全免费，国外AI工具几乎全收费。**

| | 国内 | 国外 |
|------|------|------|
| 大模型 | DeepSeek/豆包/Kimi/通义 → 全免费 | ChatGPT/Claude/Gemini → $20/月 |
| AI搜索 | Kimi/秘塔 → 免费 | Perplexity Pro → $20/月 |
| AI编程 | 通义灵码 → 免费 | Cursor/Copilot → $10-20/月 |
| AI绘画 | 通义万相/文心一格 → 免费 | Midjourney → $10-60/月 |

这个格局背后是"大模型价格战"的结果——我在"DeepSeek vs ChatGPT vs 豆包"那篇里提到过，DeepSeek免费这件事直接把整个国内市场的定价拉到了零。对用户来说这是好事，但也意味着国内工具的商业化压力更大。

**这个局面能持续多久？** 不知道。但至少2026年7月，你还有很多免费选项。

## 八、我的最终建议

**1. 不要一次性订太多。** AI工具是订阅制，每个月都扣钱。建议按月订，不要年付（就算年付便宜），这样换工具没负担。

**2. 先用免费版到"不够用"再付费。** 不要一开始就付费。先用DeepSeek免费版，用到你觉得"这个地方真的需要付费才能解决"的时候，再掏钱。

**3. 每季度做一次"订阅清理"。** 看一眼信用卡账单，把过去30天没用过的AI订阅取消。AI行业变化太快，下个月可能有新的免费平替出现。

**4. 最值得花的钱：AI编程工具 > AI大模型 > AI绘画 > AI视频。** 这是按"省时间效率"排的。一个$20/月的编程工具一天能帮你省2小时；一个$30/月的绘画工具省的是"外包设计师的钱"——你要看自己的实际需求。

**5. 这个行业变化极快。** 我今天写的价格，可能下个月就有变化。关注本号，我会持续更新。
