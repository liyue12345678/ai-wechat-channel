**你有没有过这种时刻：把一篇 30 页的 PDF 丢给聊天机器人，它回你一段通顺的中文摘要，数字对了一半，结构式认成了装饰图，参考文献张冠李戴。**

科研阅读最怕的不是模型"不够健谈"，是它**不认得论文页上的图、公式、分子，还装懂。**

9 月 13 日，上海人工智能实验室在浦江创新论坛发布**书生多模态大模型 S2**（开源名 **Intern-S2-Preview**）。人民网的表述很硬：为**长周期科研任务**和**智能体能力**准备，科学任务评测大幅领先一众开闭源旗舰——这话是官方叙事，下面我们用仓库和入口，把它翻译成你能不能用。

一句话结论：**这是给"科学工作流"开的模型，不是给闲聊开的。普通人用官网就能试；真要吃透论文和实验，35B 先试，397B 留给有算力或走官方 API 的人。**

> ⚠️ 声明：本文基于人民网报道、InternLM GitHub README、Hugging Face 模型卡整理，未做实验室级复现。科学榜数字以官方评测说明为准。

## 它是什么：不是又一个"全能王"，是科学模态

Intern-S2 这条产品线，仓库里同时放了两颗预览模型：

| 版本 | 定位 | 你需要知道的 |
|------|------|----------------|
| **Intern-S2-Preview（35B）** | 高效科研多模态 | 从 **Qwen3.5** 继续预训练；官方称在多项核心专业科学任务上，逼近万亿档 **Intern-S1-Pro**，同时保住通用推理、多模态和 Agent |
| **Intern-S2-Preview-397B** | 最强预览 | 强调三轴缩放：预训练、强化学习任务覆盖、交互式 Agent 环境；新的视觉-语言预训练，直接啃科学文献**原始页面** |

35B 的 README 还写了两个很具体的点：强化小分子空间建模、引入实值预测模块，并称是**首个同时具备材料晶体结构生成 + 强通用能力的开源模型**（官方自称，需当"主张"看）。397B 则强调：20 多个领域的科学 RL 任务联合训练、沙箱里的长程 Agent RL。

和 7 月那代 Intern-S1（235B MoE + InternViT，5T 多模态预训练、一半以上科学 Token）是同一家族的下一代预览，不是换皮聊天模型。

许可：**Apache-2.0**。Hugging Face / ModelScope 同步。部署框架写了 LMDeploy、vLLM、SGLang。长上下文示例里出现过 **512K session** + YaRN 配置（以用户指南为准，按显存裁）。

同期人民网还提到：**书生·端砚**平台升级，接入 S2 和物理世界模型 **W0**（力触、双工，往真实实验走）。W0 不是今天这篇的主角，但说明他们想把模型从"读论文"接到"进实验室"。

## 上手门槛：科研人员可以很低，本地部署可以很高

**路径 A：先别部署，直接用。**

1. 打开官方聊天：https://chat.intern-ai.org.cn/  
2. 要接代码：在 internlm.intern-ai.org.cn 注册，拿 `sk-` 开头的 Key  
3. Base URL：`https://chat.intern-ai.org.cn/api/v1`（OpenAI 兼容）  
4. 模型名：`intern-s2-preview`（35B）或 `intern-s2-preview-397b`

推荐采样（官方）：`temperature=0.8`，`top_p=0.95`，`top_k=50`。

**路径 B：自托管。** 397B 对个人不现实。35B 也不是笔记本玩具。时间序列等能力，文档写明**目前仅 LMDeploy 完整支持**。工具调用解析器走 `interns2-preview`。

> ⚠️ 坑：别把内部实验数据、未发表数据丢进公网聊天。端侧/内网方案我们周一写过星火 X2.5-4B——**科学数据的保密级别，往往比周报更高。**

## 核心能力：三个值得认真看的点

### 点 1：它吃的是"论文页"，不是纯 OCR 后再聊天

397B 介绍里最有信息量的一句：视觉预训练直接从科学文献**原始页面**学，符号语义和视觉关系放在同一套表示里，减少"先解析再理解"的信息损失。

这对应开篇那个痛点——结构式、谱图、版式，本来就不是纯文本问题。**科学多模态如果还先走一遍通用 OCR，图和公式一定先死一遍。**

我没在实验室对拍 100 篇 PDF。但产品设计是对着这个坑来的，这比再发一个"支持上传文件"的营销按钮诚实。

### 点 2：35B 打的是"任务缩放"，不是参数崇拜

35B 明确写：提升科学任务的难度、多样性和覆盖，全链从预训练到 RL。官方配图叙事是：复杂数学上，35B 可以比万亿 Intern-S1-Pro **更准、平均回复更短**（效率图，官方自绘）。

这和周四 NeoHorse、上周星火 4B 是同一句人话：**2026 年下半年，小模型的故事是"任务和轨迹"，不是"再堆 10 个 B"。**

### 点 3：Agent 是一等公民，但场景是科研，不是订机票

人民网和 README 都把**长程科研 Agent**写进卖点：黑盒环境、多框架接入、科学工作流。397B 文本推理评测最大推理长度写到 **256K**，多模态评测 **64K**（OpenCompass / VLMEvalKit / AgentCompass）。

别拿它跟 Manus 比订酒店。**该比的是：一周的文献综述、实验方案迭代、能不能少幻觉关键数字。** 后者仍然必须人审——铁律没变，科学场景更严。

生命科学、材料任务上，官方称大幅领先其他开闭源旗舰。具体分项以他们公布的图表为准，我这里不二次抄一串无法在你环境复现的小数。

## 惊喜 / 槽点

👍 做得好的：

- **入口齐全：** 聊天、API、双尺寸权重、国产算力协同（昇腾）都写了，不是只丢 hf 链接。  
- **和端砚绑定：** 模型不是孤岛，平台想接证据链和验证闭环。  
- **许可干净：** Apache-2.0，二次开发心理成本低。

👎 需要改进的：

- **Preview 就是 Preview。** 行为会变，生产系统不要锁死某一晚的 checkpoint。  
- **397B 对个人是观赏级。** 不提供轻量 App，体验两极：官网试用很顺，本地很劝退。  
- **通用闲聊不是它的 KPI。** 用它写朋友圈，属于买错菜。

## 适合谁

- **值得立刻试：** 研究生、科研助理、药化 / 材料 / 生物信息方向，日常泡 PDF 和实验记录的人。走官网即可。  
- **值得盯 API：** 实验室要接内部文献库、Agent 跑流程，又不能把数据送到通用聊天 App。  
- **暂时不用：** 只想写公众号、做短视频、做周报的人——DeepSeek Flash、豆包更合适。  
- **钱和卡：** 试用官方入口；自建先 35B，397B 当共享资源。

**一句话总结：书生-S2 把"AI for Science"从口号落成了可下载、可调用的 Preview。它不保证替你发 Nature，但比通用模型更像一个认得科学页面的同事——前提是，关键事实你自己核对。**
