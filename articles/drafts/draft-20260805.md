先看看用这套方法做出来的成品：一份关于"AI编程工具市场"的竞品分析报告——包含5家竞品的定价对比、功能矩阵、目标用户画像、市场空白分析，全程10分钟，花费0元。

**做市场调研和竞品分析，可能是AI最被低估的应用场景。**

大多数人的做法是：打开ChatGPT → 输入"帮我做一份XX行业的竞品分析" → 拿到一份看起来像模像样但经不起推敲的报告。要么数据是编的，要么分析是废话，要么竞争对手信息已经过时半年了。

**这不是AI的问题——是你的流程问题。** AI能做这件事，但需要正确的工具组合和提问方式。

这篇教程就是一套完整的、可复制的工作流。不需要任何专业背景，不需要付费工具。

## 第一步：用AI生成调研框架（2分钟）

先不要让AI写报告。先让它设计"该调研什么"。

**把下面这段提示词复制到Kimi K2.5 Agent或DeepSeek V4：**

```
你是一位资深市场研究顾问。我要做一份关于[你的行业/赛道]的市场调研和竞品分析。

请帮我设计一个调研框架，包含：
1. 应该调研哪些维度？（如：市场规模、增长趋势、头部玩家、定价策略、目标用户、差异化优势等）
2. 每个维度应该关注哪些具体指标？
3. 建议重点关注哪3-5家竞品？为什么？
4. 有没有容易被忽略但很重要的分析角度？

研究目的：[一句话描述你的目的，如"评估公司的新产品是否值得进入这个赛道"]
目标用户：[你的目标用户画像]
预算/定价区间：[如果有的话]

请以结构化的提纲形式输出，方便我后续按框架填充信息。
```

**示例：** 假设你在考虑做一个面向独立开发者的AI编程助手，你的输入就是：

- 行业/赛道：AI编程工具（面向独立开发者）
- 研究目的：评估做一个轻量级、低价的AI编程助手是否有市场空间
- 目标用户：独立开发者、个人项目为主的程序员，月预算$0-$20
- 竞品建议：Cursor、GitHub Copilot、GLM-5.2、Antigravity、通义灵码

Kimi会输出一个4-5层的调研框架。**先看一遍，把你觉得不重要的维度删掉，加一条你特别关心的。** 5分钟调整。

---

## 第二步：让AI联网搜集竞品信息（5分钟）

这是最关键的一步——**不要让AI凭记忆回答。**

绝大多数模型的知识截止日期是几个月前。竞品的价格、功能、用户数每天都在变。所以必须用**联网搜索**。

**把框架中的每一个维度，变成一个具体的搜索问题。** 比如：

> 框架中说要调研"定价策略" → 变成 "帮我搜索Cursor、GitHub Copilot、通义灵码、Antigravity的最新定价和套餐结构，2026年8月"

> 框架中说要调研"用户口碑" → 变成 "在社交媒体和技术社区搜索开发者对Cursor和Copilot的正面和负面评价，按高频关键词归类"

**使用Kimi K2.5 Agent模式：** Agent模式会自动从多个来源搜索、阅读、交叉比对。你不需要手动打开10个网页——它会帮你把这些网页读完，然后给你一个整合后的结果。

**实际操作流程：**

1. 打开Kimi App或网页版 → 切换到"K2.5 Agent"模式
2. 依次输入5-8个搜索问题（每个都是框架里的一个维度）
3. 把每次获得的信息粘贴到同一个文档里，按维度分类

**用Google AI Studio做"事实核查"：**

Kimi搜集完信息后，挑出其中最关键的数据（定价、用户数、市场份额），到Google AI Studio里二次验证：

```
请验证以下信息的准确性，并给出可追溯的来源：
- Cursor当前月费为$20/月
- GitHub Copilot个人版$10/月
- 通义灵码对个人开发者免费
- GLM-5.2的API价格为$1.40/百万输入token

对每一条，请明确标注：✅ 准确 / ⚠️ 部分准确 / ❌ 不准确，并附上来源链接。
```

**这一步花掉的5分钟，是你整份报告最有价值的5分钟。** 一个数字出错，整个结论可能是反的。

---

## 第三步：丢进DeepSeek V4做深度分析（3分钟）

现在你手里有：调研框架 + 验证过的竞品数据。

**把这两样东西一起丢给DeepSeek V4（利用它的100万Token上下文）：**

```
下面是关于[行业]的市场调研框架和已搜集的竞品数据。

请基于这些真实数据，生成一份完整的市场调研和竞品分析报告。要求：

1. 市场概况（200字以内）——市场规模、增长趋势、核心驱动力
2. 竞品矩阵——用表格呈现，至少包含：产品名称、核心功能、定价、目标用户、优势、劣势
3. 市场空白分析——当前竞品没有覆盖到但存在真实需求的方向（至少3个）
4. 机会评估——如果要进入这个市场，建议的切入角度、定价策略、差异化方向
5. 风险提示——最大的3个风险和应对思路

重要约束：
- 每一个结论都必须基于我提供的真实数据，不要编造任何信息
- 如果数据不足以支撑某个结论，标注为"基于现有数据的推测，建议进一步验证"
- 用口语化中文，不要学术腔
- 每个部分控制在300字以内，信息密度优先
```

**3分钟后，你拿到一份基础报告。**

但这时候的报告还有点"平"——全是数据和结论，缺少洞察。下一步是让它"活"起来。

---

## 第四步：追加关键洞察（2分钟）

在同一个对话里，追加以下问题（选2-3个你关心的）：

**洞察挖掘：**
```
基于上面的报告，请回答：
1. 这些竞品最容易被攻破的弱点是什么？（不是功能上的，是商业模式或用户体验上的）
2. 如果我是目标用户，我最可能在哪个环节放弃现有工具、尝试新品？
3. 一年后这个市场最大的变数是什么？（技术、政策、巨头入场……）
4. 有没有一个"反直觉"的发现？——数据指向了一个和常识相反的结论
```

**这些问题的答案，才是你报告里最有价值的部分。** 数据人人都会搜，洞察不是人人都有。

---

## 第五步：导出和呈现（2分钟）

最后一步，把报告整理成可分享的格式。

**方案A：做成飞书/Notion文档**
直接把DeepSeek输出的内容按板块复制进去，加标题、加emoji、调整格式。飞书文档的"AI美化"功能可以一键排版。

**方案B：让AI生成PPT大纲**
```
把上面的调研报告，整理成一份10页PPT的大纲。
每页包含：标题、3-5个要点、建议配什么类型的图。
第一页是封面，最后一页是总结和行动建议。
```

然后把这个大纲丢进Gamma或Canva AI——**一键生成PPT。**（我之前写过用AI做PPT的教程，链接在文末。）

**方案C：生成一页纸速览（给老板看的）**
```
把这份报告压缩成一页纸的"执行摘要"。
老板只关心：市场规模、3个关键发现、2个建议行动、1个最大风险。
用5句话以内把每一点说清楚。
```

## 进阶玩法：自动化你的调研流程

基础版做完了。如果你需要**持续监测竞品**而不是一次性调研，试试这三个进阶玩法：

### 🔥 玩法1：搭建"竞品情报自动日报"

在扣子或Dify上搭建一个简单的Agent：
- 每天早上8点自动搜索5家竞品的新闻、更新、用户评价
- 按"重大更新 / 定价变化 / 用户吐槽 / 媒体报道"分类
- 自动推送到飞书群或企业微信群

**搭建时间：** 30分钟（零代码）。一次搭建，每天自动跑。

### 🔥 玩法2：用Similarweb + AI做网站流量分析

Similarweb的免费版可以查看任何网站的流量估算、流量来源、用户地理分布。把数据导出 → 丢给AI解读 → 得到竞品的流量结构和增长趋势。

**一个实战技巧：** 让AI对比三家竞品的"流量来源占比"（搜索/社交/直接访问/外链），判断谁在做SEO、谁在投广告、谁靠口碑。这些数据可以反推竞品的市场策略。

### 🔥 玩法3：让AI扮演竞品CEO

这是我最近在用的方法，非常有启发性：

```
现在请你扮演[Cursor的CEO]。
你的产品定价$20/月，主要用户是专业开发者。
现在有一个新进入者：面向独立开发者的AI编程工具，$5/月，核心卖点是简单易用。
作为Cursor的CEO，你会怎么应对？你最担心的是什么？你最不会在意的是什么？

请基于真实的商业逻辑回答，不要虚构。
```

**这个方法的妙处在于：它逼AI从竞品的视角思考，而不是第三方的"客观分析"。** 你会得到一些在常规竞品分析中永远不会出现的情报——因为大多数竞品分析只关注"他们做了什么"，不关注"他们怕什么"。

## 常见问题

**Q: AI给的数据准不准？怎么验证？**

A: 三个原则：① 必须用联网搜索，不要让AI凭记忆回答 ② 关键数据（价格、用户数、市场份额）用Google AI Studio的Grounding二次验证 ③ 验证后的数据标注来源。遵循这三步，准确率在95%以上。

**Q: 这个流程能用在非科技行业吗？**

A: 完全可以。餐饮、教育、消费品、企业服务——只要竞品信息在互联网上可获取，这套流程就有效。唯一的区别是：传统行业的数据可能更多在行业报告和新闻里，而不是技术社区，需要调整搜索关键词。

**Q: 免费的AI工具有使用限制吗？**

A: Google AI Studio完全免费，无限使用。Kimi Agent模式免费版每天有一定的使用次数（通常够用）。DeepSeek V4网页版免费，但高峰期可能排队。**如果你一天只需要做1-2次调研，免费版完全够用。**

**Q: 和请咨询公司做调研比，差距在哪？**

A: 咨询公司做的不只是"搜集公开信息"——他们有行业专家的一手访谈、非公开数据库、方法论框架。AI可以替代"搜集公开信息+结构化呈现"这部分（约占调研工作量的60-70%），但不能替代专家判断和一手调研。**对于99%的中小企业和个人来说，AI做的调研已经超出需求了。对于需要"上董事会"级别的战略决策，仍然建议找专业人士。**
