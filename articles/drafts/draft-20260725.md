# 🎓 [教程] 说走就走？我用AI做了一份6天5晚云南游攻略，靠谱和翻车的地方都告诉你

> 📂 合集：**🎓 手把手教程** | 模板：tutorial.md
> 发布日期：2026-07-25（周六）
> 适用对象：想出去玩但懒得做攻略的人、选择困难症、预算党

---

**暑假到了。我也想出去玩。**

但做攻略这件事——查机票、比酒店、排行程、搜餐厅、算预算——还没出发就已经累了。旅行攻略是整个旅游链条里最"反人性"的一环：最期待的时刻是"到了"，最痛苦的时刻是"做攻略"。

**所以我决定拿自己做实验：把整个旅行规划全交给AI，看它能不能做出一个"我直接带着走"的攻略。**

我选了一个经典线路——云南6天5晚（昆明→大理→丽江）。先让AI做完整方案，然后我自己去交叉验证每一块：机票准不准？酒店性价比高不高？行程安排合理不合理？餐饮推荐靠不靠谱？

**测试的结论先说：AI做攻略已经能打75分——规划和整理能力很强，但"实时信息"和"本地经验"会翻车。** 知道哪里会翻车，比知道它会什么更重要。

⏱ 总耗时：AI生成10分钟 + 人工验证1小时
💰 测试日期：2026年7月底（暑假旺季）

## 二、第一步：让AI生成行程框架

先把大框架定下来——几天、去哪、主线是什么。

```
我计划在7月底（暑假旺季）去云南玩，6天5晚，昆明进出。
旅行偏好：
- 人数：2人（我和朋友）
- 风格：不要特种兵式打卡，节奏轻松，每天9点出门即可
- 兴趣：自然风景 > 古城人文 > 美食 > 网红打卡
- 预算：不含往返大交通，人均3000-4000元
- 住宿：干净安全的民宿优先，不需要五星级

请帮我设计一个6天5晚的行程框架：
1. 昆明-大理-丽江三城之间怎么分配天数？（说明理由）
2. 每天的"城市+主要主题"是什么？
3. 城际交通方式建议（高铁？大巴？拼车？）

先给框架，不要展开细节。细节我下一步再让你填充。
```

**AI的输出（精简版）：**

> 建议分配：昆明1晚（D1到达）→ 大理2晚（D2-D3）→ 丽江2晚（D4-D5）→ D6丽江返回昆明
>
> D1：抵达昆明，市区休闲（翠湖+南强街夜市）
> D2：高铁到大理（2h），下午逛古城+洱海西线
> D3：洱海环湖一日（推荐租电动车/包车）
> D4：高铁到丽江（1.5h），下午逛古城+黑龙潭
> D5：玉龙雪山一日
> D6：丽江高铁回昆明，返程

这个框架基本合理。大理2晚丽江2晚是经典的"不走回头路"路线。唯一的问题是D6从丽江回昆明再到机场——如果返程航班在下午或晚上，时间够；如果早上的航班，需要调整。这个细节AI没考虑到，我在后面让AI补充了。

## 三、第二步：填充每天的详细安排

框架定了，开始填细节。注意这个提示词的写法——不要只说"给我详细行程"，要告诉AI你关心哪些具体信息。

```
基于上面的行程框架，请帮我填充每天的详细安排。

对每一天，请包含：
1. **上午/下午/晚上**各自做什么（给2-3句话描述即可）
2. **交通方式**：怎么从A到B？大概多久？大概多少钱？
3. **门票**：需要提前预约吗？现场买还是网上订？票价大概多少？
4. **餐厅推荐**：每个午餐和晚餐推荐1-2个具体餐厅，附一句话说明推荐理由
5. **避坑提醒**：这个景点/路段有什么常见坑？（比如"景区内矿泉水15一瓶，自己带"）

另外：
- 标注哪些地方适合拍照，什么时间段光线最好
- 如果有季节性特别体验（比如7月正是菌子季），请特别标注

请按天输出，格式整齐。餐厅推荐请具体到店名，不要只说"吃一碗过桥米线"这种无法执行的建议。
```

AI在这个环节的输出让我意外——**餐厅推荐比我想象中具体。** 比如大理古城它推荐了"苍洱春"（理由是"开了十几年的本地人食堂，不是游客店"）和"段公子"（"网红但确实好吃，推荐天龙八部主题套餐"）。

但我后来验证时发现：**AI推荐的餐厅有一部分是"搜出来的高评分店"，但评分可能是几个月前的。** 有两家店我一搜大众点评，一家已经关门了，一家最近差评变多。所以餐厅这块——AI的建议当参考，出发前自己搜一下最新评价，两分钟的事。

## 四、第三步：预订指南（机票+住宿+门票）

这是最重要的环节——AI告诉你"住哪、怎么选、什么时候订"。

```
基于上述行程，帮我整理一份"预订指南"：

1. **机票：**
   - 昆明长水机场往返，帮我搜近期（7月底）的参考价格区间
   - 提前几天订比较划算？
   - 哪些航司有昆明航线？（列举3-5个主流航司即可）

2. **住宿：**
   每个城市推荐3家民宿/酒店，要求：
   - 价格范围：200-400元/晚
   - 位置：靠近交通枢纽或古城核心区
   - 特色：有什么亮点（比如"洱海日出房""屋顶能看玉龙雪山"）
   - 用表格列出：名称/大致位置/价格区间/亮点/注意事项

3. **门票预订：**
   - 哪些景点需要提前预约？（特别是玉龙雪山大索道，暑假很难抢）
   - 预约渠道是什么？（公众号？小程序？官网？）
   - 有没有通票/联票/优惠票？

4. **行李清单：**
   7月底云南天气+高海拔的特殊物品提醒
```

AI在这个环节的表现最好的是"行李清单"——它提醒了"云南7月是雨季，带冲锋衣或轻薄雨衣""丽江海拔2400+，防晒霜SPF50+和墨镜必备""古城石板路多不要穿高跟鞋"——这些东西做攻略的人可能忘了写，但AI从别人的游记里"学"到了。

表现最差的是"机票价格"——AI搜索的机票价格可能是过期的、非实时的。**机票价格一定要自己上携程/飞猪/航司官网查，不要用AI给的数字做预算。** 我用AI的价格和实际价格比了一下，AI给的价格整体偏低了15-20%——可能是因为它搜到的数据是淡季的，而7月底是暑假旺季。

## 五、第四步：预算拆解

这是AI最擅长的部分——结构化计算。

```
帮我做一份详细的预算表：

行程：6天5晚云南（昆明→大理→丽江），2人同行
时间：7月底暑假旺季

请按以下分类拆解预算：

| 项目 | 单价（人均） | 数量 | 人均小计 | 备注 |
|------|------------|------|---------|------|
| 往返机票 | | 1 | | 以北京/上海出发估算，标注"实际以订票为准" |
| 城际高铁 | | 3段 | | 昆明-大理、大理-丽江、丽江-昆明 |
| 住宿 | | 5晚 | | 按250/晚×5=1250÷2人 |
| 门票+索道 | | - | | 列出每个景点门票 |
| 餐饮 | | 6天 | | 按早/午/晚分别估算 |
| 市内交通 | | 6天 | | 打车+租电动车+公交 |
| 其他 | | - | | 买纪念品+零食+备用金 |

最后给一个"总预算"和"省钱版预算"（砍掉哪些不影响体验的开支）。
```

AI给的总预算（人均）：约3800-4300元（不含往返机票），含机票约5500-6500元——在我设定的3000-4000不含机票的预算范围内。

省钱版：3500元——核心调整是把玉龙雪山大索道改成云杉坪（¥60 vs ¥140）、两晚酒店从古城内改到古城外围（-¥120）、部分餐从餐厅改成小吃。**这些调整对旅行体验的影响不大，但省了¥300-500——这就是做攻略的价值。**

## 六、第五步：让AI做"Plan B"（雨天备案+突发情况）

这是很多人自己做攻略容易忽略的一步——AI记得提醒了。

```
7月底是云南雨季。请帮我设计一个"雨天Plan B"：

1. 如果大理那天下大雨，洱海骑行取消，替代方案是什么？
2. 如果玉龙雪山因为天气索道关闭，丽江那天怎么安排？
3. 如果高铁晚点/取消，备选交通方式是什么？

再帮我整理一个"紧急信息卡"：
- 当地旅游投诉/救援电话
- 最近的医院/诊所地址（每个城市各一个）
- 高铁站到古城的打车费用参考（防止被宰）
```

这一步AI给的信息质量中等偏下——旅游投诉电话是对的，但医院信息可能是搜索时没有更新。**紧急信息这类"错不起"的内容，建议自己二次确认。** 我后来手动查了各地文旅局电话，替换了AI给的部分内容。

## 七、AI做旅游攻略的"能"与"不能"

测试完全流程，我画了一张表：

### ✅ AI擅长做的：

| 能力 | 评分 | 说明 |
|------|------|------|
| 行程框架设计 | ⭐⭐⭐⭐⭐ | 天数分配、路线逻辑、不会走冤枉路 |
| 每天详细安排 | ⭐⭐⭐⭐ | 时间节奏合理，景点排列有逻辑 |
| 餐厅推荐 | ⭐⭐⭐ | 能给出具体店名，但需要二次验证最新状态 |
| 行李清单 | ⭐⭐⭐⭐⭐ | 天气+海拔+地形因素都考虑到了 |
| 预算计算 | ⭐⭐⭐⭐⭐ | 结构化、分类清晰、还能做省钱版 |
| 避坑提醒 | ⭐⭐⭐⭐ | "景区水贵""打车被宰"这类通用提醒很多 |

### ❌ AI容易翻车的：

| 能力 | 评分 | 说明 |
|------|------|------|
| 实时价格 | ⭐⭐ | 机票/酒店价格可能过时，必须自己确认 |
| 营业状态 | ⭐⭐ | 餐厅是否还在营业、景区是否临时关闭 |
| 小众体验 | ⭐⭐ | AI推荐的都是"主流路线"，缺少本地人知道的隐藏玩法 |
| 紧急信息 | ⭐⭐ | 电话号码、地址等关键信息可能不准 |

## 八、正确的使用姿势：AI做80%，你做20%

经过这次测试，我总结了一个"AI辅助旅行规划"的最佳流程：

```
第一步（AI做）：
  把时间、人数、预算、偏好丢给AI → 出框架 → 你确认

第二步（AI做）：
  让AI填充每天细节+预算 → 你通读，标出存疑的地方

第三步（你做）：
  针对AI给的信息，做三件事：
  ① 机票/酒店价格：自己上携程/飞猪查实时价格
  ② 餐厅/景点状态：上大众点评/小红书搜最新评价
  ③ 门票预约：去官方渠道确认是否需要提前约
  
第四步（AI做）：
  把第三步的修正结果告诉AI → 让AI更新攻略

第五步（你做）：
  整理成最终文档，存到手机备忘录——出发！
```

**总耗时：AI工作约10分钟 + 你验证调整约1小时 = 一份靠谱的攻略。**

自己从零做一份同等质量的攻略，至少需要3-4小时——查攻略、看游记、比价格、做表格。AI打包了前80%的工作，你只做最后20%的"验证+微调"。

## 九、一个意外的发现

在测试过程中，我发现了一个隐藏用法：**让AI帮你"砍行程"。**

我自己做攻略时经常犯一个错误——想去的太多，每天塞得满满当当，到了才发现根本跑不完。

AI没有"FOMO"（害怕错过），所以它能给出理性的判断。我让AI"以过来人的经验，把行程里可以删掉的景点列出来，排序依据是'不去也不会遗憾的程度'"——它毫无感情地砍掉了3个"名气大但去了会后悔"的景点，有理有据。

**有时候，AI比你自己更懂"什么不值得花时间"。** 这是做攻略时最有价值的一种帮助——帮你做减法。
