## 二、整体思路：别用AI写Excel公式，用AI替代Excel公式

很多人的第一反应是"让AI帮我写VLOOKUP"——这个方向就偏了。

**正确思路：**

```
旧流程：打开Excel → 想用什么函数 → 搜函数教程 → 写公式 → 调试 → 失败 → 重来
新流程：把数据给AI → 说"告诉我这些数据说明了什么" → 得到分析 + 图表 + 结论
```

AI不是帮你"用Excel"——AI是帮你"绕开Excel的复杂度"。

三种方式，从简单到进阶：

## 三、方式一：对话分析（最快上手）

### 适用场景
你有一份表格数据，想快速知道："这个月数据怎么样？""哪里出了问题？""有什么趋势？"

### 操作步骤

**Step 1：把数据给AI**

三种给法：
- 📸 **截图粘贴** — 最简单，所有AI都支持图片上传
- 📋 **复制粘贴** — 从Excel选中区域 Ctrl+C，直接贴到对话框
- 📎 **上传文件** — ChatGPT和Claude支持直接上传.xlsx文件

> 💡 **推荐截图或上传文件。** 复制粘贴在大数据量时AI可能截断。

**Step 2：用这段提示词**

```
我上传了一份[说明这是什么数据，如：2026年6月各区域销售数据]。

请帮我做以下分析：
1. 整体数据概览（总计、平均值、最高/最低）
2. 按[维度，如：区域/时间/产品类别]拆分对比
3. 找出异常点（哪些数据明显偏离正常范围）
4. 趋势判断（和上个月/去年同期比是好是坏）
5. 给出3条最值得关注的结论和建议

请用"先说结论、再展开细节"的结构回复。
如果发现数据中有需要我注意的问题（如数据缺失、异常偏高/低），请第一时间提醒我。
```

**实测效果（以一份虚构的销售数据为例）：**

AI回复：
> **先说结论：6月整体销售额环比下降8%，华东区拖了后腿，华南区逆势增长。**
>
> **1. 整体数据：**
> - 6月总销售额：¥4,230,000
> - 环比5月：-8.3%
> - 日均销售额：¥141,000
>
> **2. 区域对比（需要重点关注）：**
> - 华东区：¥1,520,000（环比-18%，**大幅下滑**）
> - 华南区：¥1,180,000（环比+12%，逆势增长）
> - 华北区：¥890,000（环比-3%，基本持平）
> - 西南区：¥640,000（环比-5%）
>
> **3. 异常数据提醒：**
> ⚠️ 华东区6月第3周销售额断崖式下跌（从日均¥75,000降到¥38,000），恰好在618促销结束后——可能是促销结束后需求透支，也可能是竞品在华东区做了活动。
>
> **4. 趋势判断：**
> 如果不计算618促销拉高的部分，6月自然销售其实和5月持平。问题不是"6月变差了"，是"5月促销基数太高"。
>
> **5. 三条建议：**
> 1. 立即调查华东区第3周发生了什么（竞品活动？库存问题？）
> 2. 复盘华南区为什么逆势增长——方案能不能复制到华东？
> 3. 下月做同比时，建议把促销月和非促销月分开看，避免被基数误导

**这就是AI分析的价值：它不只是"算个数"，它能看到你盯了一个小时都没发现的规律。**

## 四、方式二：生成图表（汇报必备）

光有文字分析不够——开会汇报、周报月报、老板要的是"图"。

### 适用场景
你需要把分析结果可视化：趋势图、柱状图、饼图、数据看板。

### 操作步骤

**Step 1：在方式一的基础上，追加这段提示词：**

```
好的，现在帮我把以上分析可视化。

请生成以下图表（用HTML格式，我可以在浏览器直接打开）：
1. 趋势折线图：6月每日销售额走势，标注异常点
2. 柱状图：各区域销售额对比，最好和最差用不同颜色
3. 饼图：各区域销售额占比
4. 数据卡片：总计、环比变化、最高区域、最低区域

整体风格：简洁商务风，深色背景可选项。图表之间要有排版，像一个完整的数据看板。

请输出完整的HTML文件代码，要求：
- 使用Chart.js（CDN引入，不需要我装任何东西）
- 数据直接写在代码里（不要从外部文件读取）
- 所有文字用中文
- 保存为.html文件后可以直接在浏览器打开
```

**Step 2：把AI生成的代码保存为HTML文件**

```
1. 复制AI输出的全部代码
2. 打开记事本 → 粘贴 → 另存为 "数据看板.html"（编码选UTF-8）
3. 双击打开 → 一个完整的数据看板就在浏览器里了
```

**实测效果（各AI表现）：**

| AI | HTML图表质量 | 美观程度 | 是否需要修改 |
|-----|------------|---------|-------------|
| **Claude** | ⭐⭐⭐⭐⭐ | 专业级，配色好看 | 基本不用改 |
| **ChatGPT** | ⭐⭐⭐⭐ | 干净但偏素 | 调一下颜色就好 |
| **DeepSeek** | ⭐⭐⭐⭐ | 功能完整，样式一般 | 可能需要美化 |

> 💡 三个AI都能生成可用的HTML图表。Claude的审美最好（自动选了合适的配色方案），DeepSeek完全免费也能做。

**进阶技巧：让AI生成带交互的看板**

在提示词里加这句：
```
图表之间加联动筛选：点击某个区域，其他图表自动高亮该区域的数据。
```

AI会自动加入交互逻辑——点一下柱状图的"华东区"，饼图和折线图同步高亮。**这功能以前要花钱买BI工具才能做。**

## 五、方式三：Python自动化（一劳永逸）

如果你每周都要做同样的报表——销售周报、流量周报、库存周报——上面两种方式每次都要手动操作。第三种方式让你彻底解放。

### 适用场景
固定格式的周报/月报，数据源更新后一键生成分析+图表。

### 操作步骤

**Step 1：让AI帮你写自动化脚本**

```
我每周需要做一份销售周报，数据源是一个Excel文件，格式固定：

【数据文件说明】
- 文件名：销售数据_YYYYMMDD.xlsx
- 包含字段：日期、区域、产品名、销售额、订单数、客户数
- 每周一更新上周的数据

【我需要生成的内容】
1. 整体数据汇总（总计、环比、同比）
2. 各区域对比表和柱状图
3. Top 10产品排名
4. 异常数据标注
5. 一份200字以内的文字总结

请帮我写一个Python脚本，要求：
- 自动读取最新一周的Excel文件
- 自动完成以上所有分析
- 输出一个HTML看板文件（包含图表和文字总结）
- 用pandas读取Excel，用matplotlib/plotly画图
- 加上详细的中文注释
- 我只需要每周运行一次这个脚本，所有分析自动完成
```

**Step 2：运行脚本**

```
1. 确认电脑装了Python（Win+R → 输入cmd → 输入python --version）
2. 如果没装 → 去python.org下载安装（勾选"Add Python to PATH"）
3. 安装依赖：在命令行输入 pip install pandas openpyxl matplotlib plotly
4. 把AI生成的代码保存为 weekly_report.py
5. 把Excel文件放到同一文件夹
6. 命令行运行：python weekly_report.py
7. 自动生成 report.html → 双击打开
```

**不用懂Python语法。** AI写了什么你不用全理解——你只需要知道"每周跑一次这个脚本，报表自动出来"。

> ⚠️ **避坑提醒：** 第一次运行大概率报错——不是你的问题，是AI生成的代码路径或文件名可能不匹配。别慌，**把报错信息直接贴回给AI**，它会自动修复。这个"报错→贴回去→AI修"的循环，我平均走1-2轮。

## 七、四个真实场景的专属提示词

### 场景1：运营 —— "帮我分析用户增长数据"

```
我上传了一份用户增长数据（包含：日期、新增用户、活跃用户、留存率、渠道来源）。

请帮我：
1. 判断增长是否健康（新增 vs 留存 vs 流失）
2. 哪个渠道的获客质量最高（不只是便宜，要看留存）
3. 找出增长拐点——哪一天数据发生了显著变化
4. 给出下周的增长策略建议

不要只说"优化渠道投放"这种废话，给我具体可以明天就做的动作。
```

### 场景2：财务 —— "帮我做费用分析"

```
这是一份Q2各部门费用明细。

请帮我：
1. 按部门拆分，标注超预算的部门（超多少、超在哪里）
2. 和Q1对比，费用变化最大的3个项目
3. 如果要在Q3削减10%总费用，建议从哪些项目入手
4. 用自然语言写一段"给老板看的费用分析摘要"（150字以内，说重点）

注意：所有金额精确到千位即可，不要出现小数点后好几位。
```

### 场景3：电商 —— "帮我做商品分析"

```
这是近30天的商品销售数据。

请帮我：
1. 找出Top 10和Bottom 10商品（按销售额，不是按销量）
2. 计算每个商品的"毛利贡献度"（销售额 × 毛利率，如果数据里有毛利率字段的话）
3. 有没有"卖得多但不赚钱"的商品？（销量高但毛利低）
4. 库存周转异常的商品（卖得慢但库存高）
5. 给我一个"应该做什么"的优先级清单，按对利润影响从大到小排列
```

### 场景4：HR —— "帮我做招聘数据分析"

```
这是我们Q2各岗位的招聘漏斗数据（投递→筛选→面试→Offer→入职）。

请帮我：
1. 哪个环节流失率最高
2. 哪个渠道的"入职转化率"最高（不只是投递量）
3. 和Q1对比，招聘周期是变长了还是变短了
4. 写出3条"下季度可以怎么优化招聘流程"的建议
```

## 八、新手避坑指南

**坑1：数据太脏，AI分析跑偏**
> 解法：给数据之前自己先扫一眼——有没有合并单元格？有没有"合计""小计"这种汇总行？有没有空行？**数据越干净，AI分析越准。** 如果数据确实很乱，传给AI时加一句："这份数据格式不规范，请先帮我识别哪些地方可能有问题。"

**坑2：AI给的分析太浅，全是正确的废话**
> 解法：提示词里加一句"不要给'加强投放''优化流程'这种谁都能说的建议。给我基于数据的具体发现。"另外，**追问是关键**——第一次分析往往是面面俱到的概述，追问"XX为什么下降了？"才能挖出深度。

**坑3：HTML图表打开是乱码**
> 解法：保存HTML文件时编码一定要选UTF-8。右键文件 → 用记事本打开 → 另存为 → 编码选"UTF-8" → 保存。如果还是乱码，把代码里的`<meta charset="UTF-8">`改成`<meta charset="GBK">`。

**坑4：AI生成的Python脚本跑不起来**
> 解法：别自己琢磨，把报错信息原样贴回给AI，加一句"这个脚本报错了，请帮我修复"。AI对自己的代码特别擅长Debug。

**坑5：公司数据不敢上传到AI**
> 解法：三个选择——①用脱敏数据（把真实数字替换成大致范围，不影响分析结论）；②用本地部署的开源模型（如Qwen、DeepSeek本地方案）；③用企业版ChatGPT（数据不用于训练且隔离存储）。**如果数据涉及核心商业机密，选②或③。**
