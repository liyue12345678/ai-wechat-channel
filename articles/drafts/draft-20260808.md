## 第一步：用AI写口播脚本（5分钟）

**不要从零写。从一个"爆款的骨架"开始。**

### 工具：DeepSeek V4 或 Kimi K2.5

**完整提示词（直接复制）：**

```
你是一个短视频口播脚本写手。请帮我写一条60秒的口播脚本。

选题方向：[填入你的选题，如"为什么你用的AI总是不够聪明"]
目标观众：[如"对AI好奇但觉得不会用的普通人"]
视频风格：[如"像一个懂行的朋友在聊天，不是老师在讲课"]
 
脚本要求：
1. 前3秒必须有一个钩子——提问、反常识、或场景共鸣
2. 正文按"问题→原因→解法"结构，分6-8个短段落
3. 每段不超过120字，适配口语化朗读
4. 结尾有一个具体的行动号召
5. 全文控制在250-350字（60秒朗读量）

同时给出：
- 每段对应的画面建议（如"字幕大字+人物侧脸""手机录屏操作""关键词弹窗"）
- 3-5个能当封面的标题选项
```

**示例：** 我输入选题"AI工具越来越强，为什么大部分人还是用不好？"，得到的脚本开头：

> "你上次打开ChatGPT然后对着空白的输入框发呆，是什么时候？  
> 不是你不行——是你被教错了。大多数人学AI的过程就像学开车只看说明书不上路。  
> 今天我教你一个方法，不用学任何新工具，现在就能用。"

**这个开头的钩子是"对着空白输入框发呆"——几乎每个用过AI的人都有这个经历。** 钩子不是"震惊"或"震撼来袭"——是"对，我也这样"的共鸣。

## 第二步：用AI生成分镜画面（10分钟）

有了脚本，下一步是"每一段配什么画面"。

### 方案A：文生图分镜（适合知识口播、观点类）

**工具：即梦 或 可灵（免费额度够用）**

把第一步AI生成的"画面建议"变成生图提示词。比如第一步脚本里某段的画面建议是"概念图：一个人在岔路口犹豫"，翻译成：

> "极简扁平风插画，一个人站在分岔路口前，左边路牌写着'手动'，右边路牌写着'AI'，暖色调，留白多，9:16竖屏比例，无水印"

**核心原则：全程统一风格。** 所有分镜图用同一个基础提示词模板，只改场景内容。这样6-8张图放在一起才不会"乱"。

我的固定模板：
> "[风格描述，如极简扁平插画]，[场景内容]，暖色调/冷色调，大面积留白，9:16竖屏，无水印，无文字"

### 方案B：素材混剪（适合产品展示、教程类）

**工具：剪映专业版 + AI素材搜索**

剪映的"图文成片"功能：粘贴脚本 → 自动匹配素材库画面。但有一个坑——

> ⚠️ **一定关闭"自动匹配素材"，手动上传预制分镜图或从素材库手动挑选。** 自动匹配的素材经常和文案内容脱节——比如你说"数据分析"，它给你配了一张柱状图，但你说的明明是用户调研。

### 方案C：数字人出镜（完全不想露脸）

**工具：可灵数字人 / 美图开拍 / Flyne AI**

- **可灵**：上传一张人物照片 → AI生成数字人播报片段，口型同步
- **美图开拍**：内置AI提词器，对着屏幕念就行，眼神不会飘。还有"数字人替身"模式——录一次自己，以后用替身上镜
- **Flyne AI**：上传头像图片+脚本 → 生成AI虚拟人物口播视频

**数字人的上限取决于你的"模板质量"。** 录好一段你自己的出镜素材（5分钟够用），AI学习后，后续所有视频都可以用数字替身。一次投入，永久复用。

## 第三步：AI配音（3分钟）

**不要用手机直接录。背景噪音、音量不稳、重录10遍——太消耗了。**

### 工具推荐：

| 工具 | 最佳场景 | 费用 |
|------|---------|:--:|
| **剪映AI配音** | 口播最自然，支持情绪调节 | 免费 |
| **讯飞配音** | 专业旁白，多种音色 | 有免费额度 |
| **灵剪内置TTS** | 开源可控，支持MiniMax/小米MiMo等 | 免费 |

**实操要点：**
- 语速设为 **0.95-1.05倍**（正常偏慢，听起来更舒服）
- 脚本中在每段结尾加一个空行，AI会自动做停顿
- BGM音量控制在 **15%-20%**，旁白音量 **80%**，别让音乐盖过人声

**建议：先用剪映AI配音快速出第一版 → 如果不满意，换一个音色再生成一版。** 换音色比重录简单100倍。

## 第四步：AI辅助剪辑合成（10分钟）

### 新手路线：美图开拍 / 剪映"图文成片"

**美图开拍**：输入脚本 → 选一个模板 → AI自动配画面+字幕+BGM → 预览 → 导出。10分钟内出片。

**剪映"图文成片"：** 粘贴脚本 → 手动替换不满意的素材 → 调整字幕样式 → 导出。

> ⚠️ **必须手动做的事（不能全靠AI）：**
> 1. 检查字幕有没有错别字（AI经常把同音字搞错）
> 2. 重点句子放大/变色/弹窗强调（AI不会判断哪个是金句）
> 3. 封面要自己选——AI生成的封面通常是"能用"但不是"想点"

### 进阶路线：WorkBuddy + FFmpeg自动化

如果你要批量做视频（每天3-5条），手动剪不动。建一条自动化流水线：

```
WorkBuddy（AI大脑）
  → 选题→生成脚本+分镜提示词+FFmpeg命令
    → 即梦批量生成6-8张分镜图
    → 可灵生成数字人播报片段
      → FFmpeg自动合成（背景+数字人+字幕+音频）
        → 成片输出
```

**搭建时间：** 第一次1-2小时（配置FFmpeg模板），之后每条视频从输入选题到成片只需4-5分钟。

**效果：** 关键帧字幕+数字人+背景+配音+BGM，自动套预设模板。人工只需要做两件事：选题+终审。

## 第五步：发布优化（2分钟）

### AI生成标题和封面

把脚本丢回给DeepSeek：

```
为这条短视频生成5个标题，要求：
- 15字以内
- 有数字或提问
- 有悬念
- 适合[抖音/视频号/小红书]

再生成3个封面文案，配上画面描述。
```

## 进阶玩法：三条变体路线

### 🔥 玩法1：爆款拆解翻拍
上传一条你刷到的爆款口播视频 → Kimi提取脚本结构 → 用你自己的观点替换内容 → 保持原来的节奏和句式 → AI重新生成。**不抄袭内容，复用成功结构。**

### 🔥 玩法2：一条脚本，五个平台
同一段口播脚本 → DeepSeek生成5版适配文案（抖音口语版、视频号温和版、小红书emoji版、B站长版、公众号文章版）→ 一鱼五吃。

### 🔥 玩法3：A/B测试自动迭代
同一选题 → 让AI生成两版脚本（一版感性故事开头，一版数据震惊开头）→ 两条都发 → 三天后对比数据 → 把胜出版本的结构模板化，下次复用。

## 常见问题

**Q: AI生成的脚本会不会很"AI味"？**

A: 会——如果你直接把AI输出的第一版拿来用。**加一步"口语化改造"：** 把AI脚本大声读一遍，所有读起来拗口的地方改成口语。"因此"改成"所以"，"值得注意的是"改成"关键是"，"综上所述"删掉。

**Q: 数字人会不会被平台限流？**

A: 目前各平台对数字人内容没有明确限流政策。但**纯AI生成的、低质量重复内容确实会被算法降低推荐。** 解决方法是：数字人+真人声音+原创脚本+人工终审。有"人"的痕迹在，就不会被判定为纯机器内容。

**Q: 完全不会剪视频，能做出能看的成品吗？**

A: 能。去下一个"美图开拍"，按它的引导走一遍——它把"写脚本→配音→配画面→加字幕→导出"做成了向导式流程。第一次可能花40分钟，第三条开始就是15分钟了。
