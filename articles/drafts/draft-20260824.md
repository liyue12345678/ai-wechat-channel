**8月21日，雷鸟发布了新款AI眼镜"iO"，首发1996元（国补后）。它做了一个非常反直觉的决定——把摄像头和扬声器全砍了。**

一个AI眼镜，不能拍照、不能外放听歌，那它还剩什么？

**答案可能颠覆你的预期：它反而可能是目前最"不智商税"的一副AI眼镜。**

先说结论：**雷鸟iO不是"什么都能干"的万能眼镜，而是一副把"全天记录 + 实时提示 + 翻译提词"做精的"第二大脑"。** 你要的是拍照记录生活？别买。你要的是开会记笔记、跨语言沟通、演讲提词、全天日程提醒？它几乎是为这些场景量身定做的。

## 它到底是个什么东西：一场"做减法"的赌注

AI眼镜这两年卷疯了：比摄像头、比扬声器、比算力。结果就是——**眼镜越来越重、越来越贵、续航越来越拉胯，戴不住成了最大的硬伤。**

雷鸟iO反着来，主动砍掉了摄像头和扬声器，只保留四样：**显示、麦克风、传感器、AI。**

| 项目 | 参数 |
|------|------|
| 整机重量 | **34g**（前框仅17g，前后配重≈1:1） |
| 显示 | 双目单绿色 Micro-LED，1800尼特入眼亮度，23.5°视场角 |
| 电池/续航 | 240mAh，典型约2天，全天智记18小时 |
| AI接入 | DeepSeek V4 Pro + 千问3.7 Max（后续接Kimi K3） |
| 翻译 | 时空壶BabelOS 3.0，55种语言、109种口音 |
| 售价 | 2499元 / 首发2349元 / **国补后1996元** |
| 近视配镜 | 支持0-1000度 |

**砍掉摄像头，换来的是两样东西：重量降到34g（接近普通眼镜），和"别人不怕你戴"的隐私安全感。** 这两个，恰恰是过去AI眼镜卖不动的最核心原因——太重戴不住、偷拍争议大。

## 核心功能实测：这四件事，它做得怎么样

### 1. 全天智记：把你一天"自动记下来"

这是雷鸟iO的主打。打开后，它持续记录你听到的对话，AI自动提炼重点，之后你可以回溯"上午9点我跟谁约了什么""昨天会议里那句话是谁说的"。

**首批体验者反馈：会议转写能区分说话人；全天智记可回溯历史对话、待办和约定。** 对开会多、电话多、忘性大的人来说，这是个"外挂的记忆"。

**我的判断：这是它最值钱的功能，但也是最有争议的。** 值钱在"你终于有个东西替你记事了"；争议在——它要持续收音，别人会担心。它用隐私灯强制亮起（物理连接、软件关不掉）来回应这一点。

### 2. 实时翻译：55种语言、109种口音

**支持55种语言、109种口音，翻译内容直接显示在镜片上，对方说的话优先显示。** 对出差、外贸、留学的人来说，这是"不用低头看手机"的同传体验。连续翻译续航约6.2小时。

**我的判断：这是它最"刚需"的功能。** 语言不通是硬痛点，而眼镜形态（不用举着手机）是目前最优解。如果你经常跨语言沟通，这个功能单拎出来就值回票价。

### 3. 实时提示 + AI提词器

镜片上可以显示信息看板（天气、日程、待办、股票、手机通知同步），也能当提词器——**提词内容能跟随你的语速自动滚动**。演讲、录视频、开会汇报，低头看稿的尴尬没了。

### 4. 交互：Smart Crown旋钮 + 点头摇头

靠镜腿上的"Smart Crown"旋钮（旋转/单击/双击）操作，点头确认、摇头取消。**不需要掏手机、不用喊语音助手，动作幅度很小。** 这解决了"在公共场合用AI很尴尬"的问题。

## 惊喜 👍 和 槽点 👎

**👍 做得好的：**

- **重量是硬指标。** 34g、前框17g，多名体验者的第一反应是"比想象中轻很多"，能全天戴着不难受——这恰恰是AI眼镜的生死线。
- **隐私设计想明白了。** 录音/翻译时隐私灯物理强制亮起，录音本地脱敏、传输TLS 1.3、存储AES-256，还支持一键删除导出。**它主动把"偷拍争议"从根上绕开了。**
- **显示不打扰旁人。** 显示区域开着时也很难被旁人察觉，波导眼镜常见的"彩虹纹""偏色"改善明显，户外强光下文字仍清晰。

**👎 需要改进的：**

- **单绿色显示，不是彩色的。** 看不了图片和视频，只能看文字信息。别指望拿它刷视频。
- **没有摄像头。** 想"第一视角拍vlog"的人，它满足不了。这是"减法"的代价。
- **AI能力上限取决于接入的模型。** 首批接DeepSeek V4 Pro和千问3.7 Max，后续才接Kimi K3和自研RayNeo AI——**"第二大脑"聪不聪明，还要看后续模型能不能跟上。**

## 适合谁 / 不适合谁

**✅ 你值得买，如果：**

- 你**开会、电话、面试多**，需要自动记笔记、回溯重点
- 你**频繁跨语言沟通**（出差、外贸、留学、接待外宾），受够了低头翻手机翻译
- 你**经常演讲/录视频/汇报**，需要隐形提词器
- 你在意隐私、想买AI眼镜但怕"偷拍争议"

**❌ 你不适合，如果：**

- 你想要"第一视角拍照/录像"（去露营、看演唱会记录）——**它没摄像头，直接pass**
- 你想看彩色视频、玩游戏——单色显示做不到
- 你只是"尝个新鲜"，没有上面任何一个刚需场景——**大概率吃灰**

**一句话：雷鸟iO不是"更全能的AI眼镜"，是"更聚焦的AI眼镜"。** 它把"拍"这条路砍了，把"记、译、提示"这三条路做扎实了。**买它不是因为功能多，是因为它把某几件事做到了"值得天天戴"。**
