# 🛠️ [实测] DeepSeek V4.1 Flash实测：Flash档把自家Pro挤下线，还降价了

> 📂 合集：**🛠️ 工具实测** | 模板：tool-review.md
> 发布日期：2026-09-19（周六）
> 适用对象：日常用 DeepSeek 网页或 API 的人，纠结还要不要死守 Pro 的人

---

**一个名叫 Flash 的模型，把公司自己的旗舰 Pro 挤下了线。** 这事要是发生在手机行业，大概相当于"标准版发布会当天，宣布停产 Pro"。

9 月 10 日，DeepSeek 官方发文：**DeepSeek V4.1 Flash 正式发布**。它是新结构系列里**尺寸最小**的一档，却在官方口径里，于性能、费用、速度、总用时上**全面超过 DeepSeek V4 Pro**。北京时间 **9 月 14 日 12:00** 之后，访问 `deepseek-v4-pro` 的请求，全部路由到 V4.1 Flash，并按 Flash 单价计费，直到未来的 V4.1 Pro 上线。

一句话结论：**普通用户不用纠结"要不要从 Pro 换 Flash"——官方已经替你换完了。你要搞清的是：它强在哪、账单怎么变、有哪些坑。**

> ⚠️ 声明：规格与价格以 DeepSeek 官网公告和 API 定价页为准；能力对比采用官方自述及公开评测文章，我未做实验室级复测。文末附信息源。

---

## 它是什么：最小档，却不是"缩水版"

先把参数说人话：

- **体量**：552B 参数的 MoE。新结构叫 **Causal-Encoder-Decoder（CED）**，输入和输出不对称——**输入激活约 8B，输出激活约 16B**。读得便宜，写得稍贵，这是为 Agent 那种"长输入、短决策、再长输入"的用法准备的。
- **能力**：官方强调**原生多模态视觉**。旧的 V4 Flash 和 V4 Flash Vision Exp 已下线，旧模型名会临时路由到 V4.1 Flash。
- **上下文**：API 文档写 **1M 上下文、最大输出 384K**，支持思考 / 非思考模式、工具调用、JSON、视觉。
- **调用名**：新名字直接叫 **`deepseek-flash`**。Base URL 仍是 `https://api.deepseek.com`。

技术报告侧（Hugging Face 仓库公开的《Pushing the Limits of KV Cache Compression》）还补了一刀工程数字：全局 KV Cache 压到约 **每 Token 890 字节**，相对上一代 V4 Flash 大约是四分之一，相对初代 DeepSeek-V1 号称缩了约 **437 倍**。官网同步说：对 HBM 需求降到约 1/4，对 SSD 降到约 1/8。

**Agent 场景里，缓存命中往往才是账单大头。** 他们这轮优化，打的就是这块。

WorkBuddy（含 CodeBuddy）和 OpenCode 已作为官方合作伙伴全量接入。网页端用户：打开 DeepSeek 对话，用最新模型即可，不必自己记版本号。

---

## 上手门槛：低到没有门槛

- **网页**：登录 deepseek.com，正常聊天。视觉、长文、工具，走官方产品即可。
- **API**：模型名改成 `deepseek-flash`。旧名 `deepseek-v4-flash`、`deepseek-v4-flash-vision-exp` 仍能打，但已经是"马甲"。
- **Pro 用户**：9 月 14 日中午之后，你以为在打 Pro，实际在打 Flash、按 Flash 价。这是官方行为，不是第三方网关抽风。
- **开源部署**：官宣会支持社区推理适配；大规模自建他们点名了体量——**大约 2k 卡 GPU + 存储集群**再去洽谈。对个人开发者，现实路径仍是官方 API，不是家用显卡本地 552B。

> ⚠️ 坑：别在 9 月 14 日之后还拿着旧的 Pro 压测报告做容量规划。延迟、价格、能力曲线，都已经不是 Pro-0813 那一套。

---

## 价格：闲时缓存命中可以低到"两分钱一兆"

官方 API 定价页（美元 / 百万 Token）和国内转载的人民币表是一套峰谷逻辑。人民币口径（腾讯云开发者社区等对定价页的整理，9 月 10 日 12:00 生效）：

| 计费项（每百万 Token） | 空闲时段 | 高峰时段 |
|------------------------|----------|----------|
| 输入 · 缓存命中 | ¥0.02 | ¥0.04 |
| 输入 · 缓存未命中 | ¥1 | ¥2 |
| 输出 | ¥4 | ¥8 |

高峰：**北京时间周一至周五 09:00–12:00、14:00–18:00**；周末和晚上算空闲，闲时是高峰的一半。

美元页同一张表：Flash 闲时缓存命中 **$0.003**、未命中 **$0.15**、输出 **$0.6**；高峰翻倍。同页仍列出的 V4 Pro 原价，输出大约是 Flash 的三倍量级——所以官方才敢说"按 Flash 计费"是让利。

人人都是产品经理那篇公开评测还引了 Artificial Analysis 的任务成本口径：完成一个任务约 **$0.27**，比 V4 Pro 便宜约六成。这是第三方指数，不是官网报价，当参考，不当合同。

**对你有用的只有两句：能隔夜跑的批处理，丢到闲时；系统提示词、人设、RAG 前缀，固定住，让缓存命中率上去。** Agent 长会话，不这么做，你感受不到这轮降价。

## 能力上，我相信官方哪句、不信哪句

👍 我愿意相信的：

- **结构是为成本服务的。** 8B/16B 不对称激活 + KV 压缩，和"Flash 干掉 Pro"的商业动作是自洽的：他们不是改了个营销名，是真的把 serving 成本打下来了。
- **多模态并进主模型。** 以前 Flash 和 Flash Vision 拆开，现在一个 `deepseek-flash`，产品心智更简单。
- **合作产品已接。** WorkBuddy / CodeBuddy 全量接入，说明他们准备让这颗模型成为默认生产力引擎，而不是实验室样品。

👎 需要自己留神的：

- **"全面超越 V4 Pro"是官方测试口径。** 你可以当作切换理由，但不要当成所有榜单、所有中文写作任务的永久第一。旗舰横评我们 9/11 写过：GPT-6 Astra、Claude Fable 5.1、Gemini 3.8 Flash 不在一个购物车里。
- **有评测提到输出 Token 偏多。** 单价低、想得多，账单不一定更低。长思考任务建议看实际用量，不要只看价目表。
- **V4.1 Pro 还在未来。** 现在的 Flash 是"暂时的默认旗舰"。过几个月名字还会再洗牌，别把模型名写死进生产配置还不做兼容。

8 月 27 日那篇 DeepSeek 多模态，测的是 V4-Flash-Vision 看图、转代码。**今天这篇不重复那个角度**——V4.1 的新闻点是：**产品线折叠 + 价格 + 把 Pro 退役。**
