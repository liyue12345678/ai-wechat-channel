# 📖 [教程] 用AI批量生成短视频脚本：输入你的账号定位，5分钟产出7天内容

> 📂 合集：**📖 手把手教程** | 模板：tutorial.md
> 发布日期：2026-06-30（周二）
> 测试环境：DeepSeek + Claude，2026年6月

---

**先说清楚：AI不会替你写出爆款脚本。但它能帮你在5分钟内搭出7天的选题+脚本框架，你只需要往里填"你才知道的东西"。**

我做了一个实验：给AI一个虚构的"数码博主"账号定位，让它生成一周7条短视频脚本。结果——选题逻辑在线，钩子写法专业，口播节奏合理。每一篇只要改30%就能出片。

**这意味着：一个运营，一个人，一个AI，真的能撑起一个日更号。**

## 一、为什么写这篇？

做自媒体的朋友最怕的不是"写不好"——是"不知道今天拍什么"。

我自己写了两个月公众号，最焦虑的时刻永远是：打开编辑器，光标在空白页上闪。选题枯竭比写得差更致命。

短视频更残酷——**日更是基础门槛，断更一天算法就不认识你了。**

所以我花了这个周末，专门研究了一个命题：**能不能让AI帮我搭建一套"选题+脚本"的半自动生产线？**

答案是：能。而且效果比我预期的好。

## 二、整体思路：别让AI从零创作，给它"脚手架"

很多人的第一反应是："帮我写一个数码测评的短视频脚本"——然后AI给了一篇泛泛的废话。

**问题出在：AI不知道你是谁、你的受众是谁、你的账号调性是什么。**

正确做法分四步：

```
第一步：喂定位 → AI了解你的账号
第二步：出选题 → AI生成7个选题，你挑选/修改
第三步：写脚本 → 逐条生成，你审核修改
第四步：建模板 → 固化流程，以后5分钟出一周的
```

下面一步一步来。

---

## 三、第一步：喂定位（最关键的一步）

**把下面这段提示词复制到AI对话框，替换方括号里的内容：**

```
你是一个短视频脚本策划。在开始写脚本之前，请先仔细阅读我给你的账号信息，确认你理解了我的定位和风格后，回复"收到，请告诉我你想做什么内容"。

【我的账号信息】
- 平台：[抖音 / 小红书 / 视频号 / B站]
- 账号名称：[你的账号名]
- 赛道/领域：[例如：数码测评 / 美食探店 / 职场干货 / 母婴好物]
- 目标受众：[例如：25-35岁上班族，对科技感兴趣但不太懂技术]
- 内容风格：[例如：轻松口语化、有梗、不端着、每期30-60秒]
- 对标账号：[列1-2个你喜欢的同赛道账号]
- 过往爆款（如果有）：[列1-2条你数据最好的内容]
- 我的独特优势：[例如：我是前手机工程师，懂供应链内幕]

请根据以上信息，先总结一下你对这个账号的理解（一句话），然后我们开始。
```

**示例（我用一个虚构数码博主测试）：**

AI回复：
> 收到。我理解的账号定位：一个"懂技术但不说教"的数码博主，面向普通消费者，用"前工程师"的视角拆解产品，风格轻松但有干货。对标"何同学"的叙事感 + "钟文泽"的快节奏，但更口语化。

你看——AI已经比你更清楚你的定位了。

---

## 四、第二步：出选题（5分钟出7个）

确认定位后，继续对话：

```
好的，现在帮我生成下周7天的选题。要求：

1. 每天一个选题，每个选题一句话说清楚
2. 选题类型要多样化，参考以下比例：
   - 2条：热点借势（最近数码圈发生的事）
   - 2条：干货/教程（教会观众一个具体技能）
   - 1条：测评/体验（真实上手某个产品）
   - 1条：观点/态度（对某个行业事件的看法）
   - 1条：互动/话题（引导评论和讨论）
3. 每个选题后面标注：
   - 预期时长（30秒 / 60秒 / 90秒）
   - 为什么应该做这个选题（一句话）
   - 标题钩子怎么写（给一个吸引人的开头句）
4. 选题之间要有差异——不要7条都讲手机或都讲耳机

输出格式：表格
```

**AI输出的示例（数码博主）：**

| 周几 | 选题 | 类型 | 时长 | 钩子开头 |
|------|------|------|------|----------|
| 周一 | iPhone 17传闻汇总——这些爆料靠谱吗？ | 热点借势 | 60秒 | "关于iPhone 17的爆料，我已经看了30多条了，今天告诉你哪些是真的。" |
| 周二 | 手机拍照的"专业模式"到底怎么用？3个参数讲清楚 | 干货教程 | 90秒 | "你花8000块买的手机，拍照永远只用自动模式？这3个参数让你照片质感翻倍。" |
| 周三 | 我用了3天199元的骨传导耳机，结论出人意料 | 测评体验 | 60秒 | "199块的骨传导耳机，和韶音差在哪？我戴了3天，答案你想不到。" |
| 周四 | 折叠屏是未来还是智商税？我说点大实话 | 观点态度 | 90秒 | "折叠屏卖了3年了，我修过的比用过的还多。今天不吹不黑说清楚。" |
| 周五 | 旧手机别扔！4个变废为宝的用法 | 干货教程 | 60秒 | "你抽屉里那台旧手机，还能干4件新手机干不了的事。" |
| 周六 | 618手机怎么选？5000以内最强机型一句话推荐 | 热点借势 | 60秒 | "618就这几天了，朋友问我5000块买什么手机，我回了3个字。" |
| 周日 | 评论区告诉我你用过最差的一部手机，我先说 | 互动话题 | 30秒 | "用了十几年手机，最让我崩溃的一部你们绝对猜不到。该你了。" |

**注意：AI生成的选题不能直接照搬！** 你必须做两件事：
1. **替换成你真正用过/经历过的东西**——AI不知道你用过骨传导耳机，但你真用过就换上去
2. **加入时效性元素**——AI不知道今天是618还是双11，你得把时间相关的内容换成对的时间

## 五、第三步：逐条生成脚本（核心环节）

选题确认后，逐条让AI出脚本。这是产出环节，提示词要更细：

```
好的，现在帮我写第[X]条的完整口播脚本：[选题名]

要求：
1. 口播风格：[口语化/有梗/不端着]，语速中等偏快
2. 结构：
   - 前3秒：钩子（让观众停下来）
   - 第3-15秒：铺垫（为什么你要看这个视频）
   - 第15秒-结尾：主体内容（分3个要点）
   - 最后5秒：引导（关注/评论/点赞的理由）
3. 时长控制在[30/60/90]秒，按正常语速约[80/160/240]字/分钟
4. 标注：
   - 🎬 画面建议：[这段口播配什么画面]
   - 📝 屏幕文字：[字幕/花字/关键信息卡]
   - 🔊 BGM建议：[什么类型的背景音乐]
5. 脚本用以下格式输出：
   [时间码] | 口播文案 | 画面 | 备注

然后把完整口播文案单独输出一遍，方便我直接对着念。
```

**AI输出示例（"旧手机变废为宝"脚本片段）：**

```
[0:00-0:03] | 你抽屉里那台旧手机，还能干4件新手机干不了的事。 | 快速切3台旧手机的镜头 | 语气要有"揭秘感"
[0:03-0:10] | 很多人换了新手机，旧的就扔抽屉吃灰。但你不知道——旧手机有几个天然优势：不用心疼电池、不用怕摔、App随便装。 | 手机从抽屉拿出来的画面 | 加字"不用心疼" "不用怕摔"
[0:10-0:20] | 第一，车载导航专用机。旧手机往支架上一放，专门导航，新手机该干嘛干嘛，不用担心导航吃电。 | 旧手机装车上导航的画面 | 分屏：左边导航，右边新手机聊微信
[0:20-0:30] | 第二，家里的安防摄像头。下个免费App，旧手机秒变监控，还能双向通话。比买个摄像头便宜多了。 | App界面演示 | 加字"0元监控方案"
...
[0:50-0:55] | 这4个用法我自己全试过，尤其第一个导航专用的，用了两年了，真好用。 | 博主面对镜头说话 | 
[0:55-0:60] | 关注我，下期告诉你旧手机怎么卖二手最不亏。 | 账号logo弹出 | 加关注引导动画
```

**💡 关键技巧：**
- 让AI加"画面建议"和"BGM建议"——它生成的口播文案会跟着画面节奏走，更自然
- "备注"栏里让AI写表演提示——新手博主最大的帮助
- 把完整口播文案单独输出——方便复制到提词器

## 六、第四步：建模板（一劳永逸）

做完第一周后，把整个流程固化成模板。以后每周只需要：

```
用上次数码博主账号的定位和风格，按照之前约定的选题比例，帮我出下周7天的选题。选题方向更新为6月30日-7月6日这周的热点和内容。

（然后把上周生成的脚本模板贴进来做参考）
```

**整个流程耗时：**
- 生成选题：2分钟
- 挑选/修改选题：5分钟
- 逐条生成脚本（7条）：15分钟
- 人工修改润色：每条5分钟×7条=35分钟
- **总计：约1小时出一周的量**

对比以前全靠手写——每条脚本至少40分钟，一周7条就是4-5个小时。

```
- 3条：探店（不同价位/不同菜系）
```

**职场干货博主：**

```
- 受众：工作1-5年的职场人
```

```
请帮我生成本周选题。注意：不要推任何品牌，只讲"怎么选"和"怎么用"。
```

## 八、常见翻车现场 & 解法

**翻车1：AI写的脚本念着像AI写的**
> 解法：把AI生成的脚本大声念一遍。任何你平时不会说的词（"综上所述""值得注意的是""毋庸置疑"）全部删掉。**AI写骨架，你填血肉。** 那些数据、洞察、个人经历——只有你知道的东西——才是观众关注你的原因。

**翻车2：AI选题太泛，什么赛道都能用**
> 解法：选题里必须有"你才知道的信息"——你用过的东西、去过的地方、踩过的坑。如果AI给的选题换一个博主也能做，说明不够好。

**翻车3：AI生成的口播太书面化**
> 解法：提示词里加一句"用你和朋友微信聊天的语气写，不要写作文"。或者在生成后追加一句："把上面这段话改成口语版，像在和朋友聊天。"

**翻车4：7条脚本AI给了一个套路**
> 解法：每次生成新脚本时，把前面已生成的脚本标题贴进去，加一句："风格和结构要和之前不一样，换一种开头方式。"

## 九、完整提示词懒人包

直接把下面这三段按顺序发给AI就能用：

**第一段（初始化）：**
```
你是一个短视频脚本策划。请先阅读我的账号信息：
- 平台：[填]
- 赛道：[填]
- 风格：[填]
- 受众：[填]
- 我的优势：[填]

确认你理解了定位后，回复"明白了，开始吧"。
```

**第二段（出选题）：**
```
帮我出下周7天选题。类型比例：热点2条+干货2条+测评1条+观点1条+互动1条。每个选题标注时长、为什么做这个选题、钩子怎么开头。用表格输出。
```

**第三段（逐条写脚本）：**
```
好的，写第[X]条脚本。结构：前3秒钩子→铺垫→3个要点→结尾引导。标注画面建议、屏幕文字、BGM。完整口播单独输出方便念稿。
```

## 十、最后的实话

这篇教程的标题是"5分钟产出7天内容"。

但说实话——**AI负责的是从0到70分的那段路，从70分到90分那段，还是你的。**

选题的方向感、观点的独特性、经历的真实感——这些AI给不了。

但AI能帮你干掉所有重复劳动：搭框架、写初稿、排时间。**你只做AI做不了的那30%。**

而正是这30%，决定了观众是划走还是点关注。
