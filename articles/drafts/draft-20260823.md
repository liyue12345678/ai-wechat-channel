### 事件1：DeepSeek"长眼"了——多模态视觉模型上线，图片封顶384 token、千图只要1块钱

**📌 发生了什么：**

8月21日，DeepSeek在官方API平台上线了实验性多模态视觉理解模型 **V4-Flash-Vision-Exp**（名字里的"Exp"是Experimental，官方明确不建议直接上生产）。

一句话说它是什么：**DeepSeek第一次真正"看懂"图片了。** 支持文字+图片混合输入，可以看图问答、截图转代码、设计稿转网页。官方称其多模态Agent能力"已接近 Claude Opus-4.8"，纯文本能力与 V4-Flash 正式版持平——**不是牺牲文本换视觉。**

**📌 为什么重要：**

真正炸的不只是"会看图"，是它的**定价**：

- 图片转成 token 计费，**单张图片最多只占 384 个 token**，没有"视觉溢价"
- 算下来**一张图约 0.001 元，1000张图约 1.15 元**（低谷时段不到 0.6 元）
- 对比竞品：同样一张 1024×1024 的图，Claude Sonnet 4.6 要 1334 token（千图约29元）、GPT-5.4 Vision 要 765 token（约1.9美元）、Gemini 3.1 Pro 要 258 token——**DeepSeek 比最贵的便宜 25～50 倍**

背后的技术是它自研的"视觉原语"框架——把图像元素压缩成空间坐标式原语，而不是把整张图拆成 patch。**翻译成人话：别人看图是"逐像素扫描"，它是"先看懂结构再描述"，所以又准又省。**

**📌 和你的关系：**

短期：想白嫖一个"能看图、能做Agent"的国产模型？去 DeepSeek 开放平台调 `deepseek-v4-flash-vision-exp`。截图转代码、图片转表格、设计稿转网页这类活，它的性价比目前没有对手。

中期：**多模态终于从"贵的专属"变成"白菜价"。** 这意味着所有"看图干活"的场景——客服看图、电商做图、质检识图、做PPT、复刻网页——成本会断崖式下降。上半年还要为"视觉能力"付高价，下半年可能就免费了。

### 事件2：马斯克买下Cursor——工具链，成了巨头的新战场

**📌 发生了什么：**

本周，多家媒体报道：**马斯克收购了 AI 编程工具 Cursor**。此前 Cursor 是程序员圈最火的 AI IDE 之一，而 xAI 旗下已有 Grok 和自有编程生态。这笔收购被解读为 xAI 布局"模型路由与调度层"、卡位开发者入口的一步。

**📌 为什么重要：**

这周资本市场传递的信号非常统一：**光有模型不够，得握住"离用户最近的那层工具"。**

看看这几件事放在一起：Anthropic靠 Claude Code 占了 GitHub 7% 的代码提交、首次盈利；现在马斯克买 Cursor、英伟达买 Poolside（见下条）——**巨头们正在从"卷模型"转向"卷工具链和分发"。** 谁握住开发者每天打开的那个窗口，谁就握住下一轮增长。

**📌 和你的关系：**

短期：用 Cursor 的人不用慌，产品大概率照常用，甚至可能接入更强的 Grok。真正要关注的是趋势——**你的"AI入口"会越来越集中到少数几个工具上。** 现在选定的那个工具，未来可能决定你用的是谁家的模型。

> 🔗 来源：本周综合财经与科技媒体报道（zhiding.cn、aitop100 每日AI资讯等）

### 事件3：英伟达60亿买Poolside、博通拟融600-1000亿——算力巨头继续All in

**📌 发生了什么：**

两条资本新闻放在一起看：

- **英伟达以 60 亿美元拿下 Poolside 的模型授权，并另投 10 亿美元**（投后估值 120 亿）——这是英伟达向"模型层"纵向整合的又一动作，从卖铲子的，开始自己下场挖金子。
- **博通拟融资 600～1000 亿美元**，用于支持 AI 芯片项目，Anthropic 等公司直接受益。

**📌 为什么重要：**

一边是"AI公司到底赚不赚钱"的争议（上周五我们刚聊过），一边是算力巨头用真金白银继续下注。**英伟达和博通，用几百上千亿美元投票：AI的算力需求，还远没到顶。**

**📌 和你的关系：**

这跟普通人的关系很间接，但有一个信号值得记住：**AI 的"军备竞赛"没有减速，反而在加速。** 算力在涨、模型在开源、工具在被收购——你不需要理解每一笔交易，只需要知道：**这场牌局还远没结束，你现在学用AI，不晚。**

## 📊 本周信号总结

如果只用一段话总结这一周：**多模态，正式成为主战场。**

DeepSeek把视觉能力打到"千图1块钱"，阿里批发式开源图像/语音/视频/音乐模型，商汤跟上，雷鸟把多模态塞进眼镜——**一周之内，所有玩家都往同一个方向挤：让AI从"只看文字"进化到"看得见、听得懂、说得出"。**

还记得上周我们说"价格战结束、价值战开始"吗？这周补上了下半句：**价值战的下一场，叫多模态。** 因为文字能力已经卷到头了——文本模型之间差距越来越小，只能靠价格拉开（所以才有"价格战取代能力战"的说法）。**但视觉、语音、视频这些"多模态"能力，还处于快速上升期，谁先补上，谁就有新的溢价空间。**

对普通用户，结论很朴素：**接下来你手里的AI会越来越"全能"——能看懂你发的截图、能听懂你说话、能帮你生成图和视频。** 不用追每个新闻，只需要记住一件事：**AI正在从"聊天机器人"变成"多模态助手"，你的用法也该从"打字提问"升级到"丢张图、说句话、让它直接干活"。**
