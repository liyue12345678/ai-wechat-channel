## 一、先看看你能做出什么样的网站

在开始之前，先明确"AI搭网站"能做什么、不能做什么。

**能做的（完全没问题）：**
- 个人作品集/简历网站
- 公司官网/落地页
- 博客/内容展示站
- 简单的工具型页面（计算器、生成器）
- 产品介绍页/活动页

**暂时做不了的（或者很勉强）：**
- 复杂的用户登录/支付系统（需要后端知识）
- 社交平台级别的大型应用
- 实时协作功能
- 需要数据库的复杂动态网站

**对于90%的"我想有个网站"需求——个人主页、项目展示、博客——AI完全够用。**

## 三、正式开始：搭建你的网站

我以"做一个个人作品集网站"为例。这是最常见的需求，你学会了以后，改一个Prompt就能做其他类型的网站。

### 步骤1：创建项目（2分钟）

```
1. 打开 Cursor
2. 点击 "Open Folder" → 在桌面新建一个文件夹叫 "my-website" → 选择它
3. 左侧会出现一个空的项目面板
4. 按 Ctrl+L（Mac: Cmd+L）打开 AI 聊天面板
```

### 步骤2：用一句话生成整个网站（核心步骤）

把下面这段提示词复制到 Cursor 的聊天框里，然后按回车：

```
帮我做一个个人作品集网站，要求：

1. 单页面设计，包含以下区块：
   - 顶部导航栏（首页、关于我、作品、联系方式）
   - 首屏大标题区域（名字、一句话介绍、一个按钮跳转到作品区）
   - 关于我（一段自我介绍 + 技能标签）
   - 作品展示（3-4个项目卡片，每个有标题、描述、配图占位、链接按钮）
   - 联系方式（邮箱、GitHub链接、Twitter链接）
   - 页脚

2. 设计要求：
   - 简洁现代风格，白色背景 + 深色文字 + 蓝色主题色
   - 移动端自适应（手机上也能看）
   - 滚动时有平滑过渡动画

3. 技术栈：纯HTML/CSS/JS，不用框架，所有代码写在一个HTML文件里。

4. 内容先用占位文字（比如"张三 | 产品设计师"），我后面自己改。
```

> 💡 **这段提示词的逻辑**：先告诉AI"要什么区块"→ 再告诉它"要什么风格"→ 再限定"用什么技术"→ 最后说"内容用占位符"。这个公式适用于任何类型的网站——改第一部分的"区块内容"，就能做出博客、公司官网、活动页。

AI会在30秒到1分钟内生成完整的HTML代码。Cursor会自动在项目里创建文件并写入代码。

### 步骤3：预览你的网站

```
在 Cursor 里，右键点击生成的 index.html → "Open with Live Server"
（如果没有这个选项，安装一个叫 "Live Preview" 的扩展）

浏览器会自动打开，你就能看到你的网站了！
```

**第一版大概率是能用的。** 结构完整、配色合理、手机上也能看。但肯定有些地方你想改——接下来是关键。

> ⚠️ 这里有一个坑：**不要自己去改代码。** 很多人在这一步看到HTML代码就慌了，试图手动修改——不用。继续用AI对话的方式改，就像你跟设计师说"把这个改成蓝色"一样。

## 四、修改和优化：用对话的方式"指挥"AI

这是AI搭网站和传统方式最大的区别——**你不需要理解代码，你只需要用自然语言描述你想改什么。**

### 修改示例1：改颜色

在 Cursor 聊天框里继续对话：

```
把主题色从蓝色改成深绿色（#1a5632），导航栏和按钮都用这个颜色。
```

AI会找到所有用到蓝色的地方，自动替换成深绿色。3秒搞定。

### 修改示例2：换内容

```
把我的名字改成"李四"，介绍改成"一个有5年经验的UI设计师，擅长B端产品设计。曾就职于字节跳动、美团。"
技能标签改成：Figma, Sketch, Principle, 用户研究, 交互设计, Design System
```

AI会自动把占位文字替换成你的真实内容。

### 修改示例3：加一个区块

```
在作品展示和联系方式之间，加一个"工作经历"区块。
时间线样式，3段经历，每段包括：公司名、职位、时间、一句话描述。
```

### 修改示例4：调整移动端效果

```
在手机上，首屏标题太大了，把字号从48px改成32px。作品卡片在手机上改成单列排列。
```

---

**核心思想：每次只改一个东西，描述具体。** 就像你对着一个设计师说话——"这里改成蓝色""那里加个阴影""这个字太大了"。

如果一次改太多、描述太模糊，AI可能改错。**一条对话 = 一个需求 = 立刻预览验证。** 这个节奏能让你在1-2小时内迭代出一个满意的网站。

## 五、上线发布：让你的网站"活"起来

网站做好了，现在需要让它能被别人在浏览器里访问。

### 方案一：GitHub Pages（免费，推荐新手）

这是最简单的方式，5分钟搞定：

```
1. 在 Cursor 里按 Ctrl+Shift+P，输入 "Git: Initialize Repository" → 回车
2. 左侧源代码管理面板 → 输入提交信息 "first version" → 点击提交
3. 打开 GitHub 网页 → 右上角 "+" → "New repository"
4. 仓库名填 "my-website" → 勾选 Public → Create
5. 回到 Cursor，按 Ctrl+Shift+P → "Git: Add Remote" → 粘贴 GitHub 仓库地址
6. 左侧源代码管理 → 点击 "Publish Branch"
7. 回到 GitHub 网页 → Settings → Pages → Source 选 "main" → Save
8. 等1-2分钟，GitHub 会给你一个网址：https://你的用户名.github.io/my-website/
```

**这个网址可以发给任何人，全世界都能访问。完全免费。**

### 方案二：Vercel（也免费，稍微好看一点）

如果你的网站不止一个HTML文件（后面加了图片、CSS文件等），Vercel体验更好：

```
1. 去 vercel.com → 用 GitHub 账号登录
2. 点击 "New Project" → 选择你的 my-website 仓库 → Deploy
3. 等30秒，Vercel 给你一个网址：https://my-website.vercel.app
4. 以后每次在 Cursor 里改了代码 → 提交 → Vercel 自动更新网站
```

两种方案都免费。GitHub Pages适合单文件项目，Vercel适合稍复杂一点的。

### 方案三：绑定自己的域名（可选，¥30-50/年）

如果你有自己的域名（比如在阿里云/腾讯云买的），可以绑定到GitHub Pages或Vercel上。网上搜"GitHub Pages 绑定域名 教程"，10分钟搞定。

## 六、进阶玩法：三种变体

基础版掌握了，试试这三种变体——改一行Prompt就能做完全不同的事。

### 🔥 玩法1：把作品集改成公司官网

```
把上面的提示词里的"作品展示"改成：
- 产品/服务介绍（3个服务，每个有图标、标题、描述）
- 客户案例（3个案例，每个有logo占位、一句话结果）
- 团队介绍（4个头像占位、名字、职位）

其他不变。10分钟变出一个公司官网。
```

### 🔥 玩法2：做一个AI工具导航站

```
把提示词改成：
帮我做一个AI工具导航站，包含：
- 顶部搜索框（可以输入关键词过滤）
- 分类标签栏（写作、绘画、编程、视频、办公）
- 工具卡片网格（每个卡片：工具名、一句话介绍、免费/付费标签、官网链接按钮）
- 大概20个工具占位

这个稍微复杂一点，AI可能需要2-3轮迭代，但逻辑是一样的。
```

### 🔥 玩法3：加一个AI聊天功能

```
在现有网站上嵌入一个AI聊天窗口：
在页面右下角加一个浮动聊天按钮，点击后弹出聊天窗口。
窗口里是一个嵌入的AI客服——可以用第三方服务如 Chatling 或 Dify 的嵌入代码。

把这个功能加到你的联系页面里，访客可以直接和AI对话。
```

> 这个玩法稍微进阶，需要你注册一个AI客服工具（Chatling有免费版），获得一段嵌入代码，然后让Cursor帮你加到网站上。

## 七、常见问题

**Q: AI生成的代码有bug怎么办？**
A: 把报错信息（浏览器按F12→Console里的红字）直接复制给Cursor的AI聊天框，说"修一下这个bug"。99%的情况AI自己能修。如果修了3次还没好——把整个文件删了，重新输入提示词，换一个说法。有时候换个角度描述需求，AI就能生成正确的代码。

**Q: AI生成的网站很难看怎么办？**
A: 用自然语言描述你要的风格。不要只说"好看一点"——说具体："简约风、大量留白、无衬线字体、莫兰迪配色"。可以参考你喜欢的设计网站，告诉AI"参考Apple官网的风格"。AI理解设计风格词的能力很强。

**Q: 我想做的东西比教程里的复杂很多？**
A: 从最简单的版本开始，然后逐步加功能。不要一上来就扔给AI一个"帮我做一个人人网"。先做"只有一个页面的基础版"→ 预览 → 满意了 → "加上用户登录"→ 预览 → 满意了 → "加上动态发布"。**分步做，每步都验证。** 这是用AI编程的核心心法。

**Q: 免费的AI额度用完了怎么办？**
A: Cursor免费版每月2000次请求，做一个网站大概用100-200次。如果超了，可以换Windsurf（也是免费）、或者用ChatGPT/DeepSeek生成代码然后手动复制粘贴。或者等下个月重置。
