## 第一步：你是哪类用户？对号入座

在比较模型之前，先搞清楚自己的使用模式。**95%的人属于以下四种之一：**

| 类型 | 典型行为 | 每天AI用量 | 付费意愿 |
|------|---------|:--:|:--:|
| 🟢 **轻度用户** | 聊天、翻译、偶尔写文案、查资料 | 5-20次 | 不想花钱 |
| 🟡 **重度办公** | 写文档/周报/邮件、做PPT大纲、整理纪要、分析数据 | 20-50次 | 愿意花小钱 |
| 🔵 **专业创作者** | 写深度文章、做竞品分析、批量生成内容、搭建工作流 | 50-100次 | 愿意花$20/月 |
| 🔴 **开发者** | 写代码、Debug、全栈项目、Agent开发、私有化部署 | 100+次 | 需要API，对价格敏感 |

**如果你不确定自己是哪类——你是🟢轻度用户。** 大多数人和你一样。

## 第二步：6款主流模型，各自最擅长什么？

### 🥇 DeepSeek V4（网页版免费）

**核心定位：中文写作和日常工作的全能王。**

| 最擅长 | 不太行 |
|--------|--------|
| ✅ 中文文章写作（公众号/小红书/知乎风格） | ❌ 英文复杂推理不如Claude |
| ✅ 1M上下文——丢整本书进去分析 | ❌ 高峰期偶尔排队 |
| ✅ 联网搜索+文件上传，信息获取能力强 | ❌ 图片生成不支持 |
| ✅ 完全免费，注册即用 | |
| ✅ Thinking模式让推理过程透明 | |

**最适合：🟢轻度用户、🟡重度办公。** 如果你的主要场景是"写东西"，DeepSeek V4目前是中文领域最好的免费选择。

---

### 🥈 Kimi K3 / K2.5（网页版+App免费）

**核心定位：搜索和信息整合能力最强的AI。**

| 最擅长 | 不太行 |
|--------|--------|
| ✅ 联网搜索——一次性搜几十个网页交叉验证 | ❌ 纯代码生成不如GLM-5.2和Claude |
| ✅ Agent模式——自动完成多步骤任务 | ❌ 对话风格偏"理性"，不如DeepSeek口语化 |
| ✅ 四种模式切换（Instant/Thinking/Agent/Swarm） | ❌ Agent模式免费额度有限 |
| ✅ 长文处理——读论文、读报告、读合同 | |
| ✅ 极速模式日常对话响应飞快 | |

**最适合：🔵专业创作者、需要做调研的人。** Kimi的搜索+长文组合是做市场调研、文献综述、合同审查的利器。

---

### 🥉 GLM-5.2（Z.ai网页版免费 + MIT开源）

**核心定位：免费AI编程之王。**

| 最擅长 | 不太行 |
|--------|--------|
| ✅ 编程——Code Arena全球可用模型第1 | ❌ 纯文本模型，不支持图片输入 |
| ✅ MIT开源——下载、修改、商用，全免费 | ❌ API不免费（$1.40/M输入） |
| ✅ 1M上下文+长程编程，16个bug全跟踪 | ❌ 中文写作不如DeepSeek口语化 |
| ✅ 微信小程序开发——目前最好的AI | ❌ 网页版可能被分配到旧版模型 |
| ✅ 国产算力全适配（华为/寒武纪等8家） | |

**最适合：🔴开发者。** 如果你写代码，目前性价比最高。如果你写微信小程序，这是唯一解。

---

### 🏅 Qwen3.8-Max（API付费 + 下周开源权重）

**核心定位：能力最强的中国开源模型——即将免费。**

| 最擅长 | 不太行 |
|--------|--------|
| ✅ 自主长程任务——16天/265次提交 | ❌ API贵（¥12/M输入，是DeepSeek的12倍） |
| ✅ OSWorld电脑操作排名第1 | ❌ "下周开源"还没兑现 |
| ✅ 原生多模态——图片+文字混着来 | ❌ 开源协议未公布（可能是坑） |
| ✅ 专业办公——法务/金融/芯片设计 | ❌ 模型太大，本地部署硬件门槛极高 |
| ✅ 2.4万亿参数，原生视觉理解 | |

**最适合：🔴需要私有化部署的企业、Agent开发者。** 如果下周权重如期开源且协议友好，它会成为企业AI部署的首选。但现在还是"期货"——等到真正能下载再说。

### 🎖️ Claude（网页版免费有限 + Pro $20/月）

**核心定位：复杂推理的天花板。**

| 最擅长 | 不太行 |
|--------|--------|
| ✅ 复杂推理和逻辑分析——业界最稳 | ❌ 免费额度很低，一天几次就没了 |
| ✅ 长文写作有"人味"，不机械 | ❌ 不联网（截止到训练日期） |
| ✅ 代码质量高，Bug修复极准 | ❌ 中文偶尔"翻译腔" |
| ✅ 安全教育做得最好（有时是缺点） | ❌ 安全护栏有时过度拒绝合理请求 |
| ✅ 150K上下文+Artifacts交互式输出 | |

**最适合：🔵专业创作者中需要深度推理的人。** Claude写的文章读起来不像AI写的——这对需要"有温度的文字"的场景是核心优势。但它不联网，需要时效性的任务（如新闻分析、价格查询）不能靠它。

---

### 🎖️ ChatGPT / GPT-5.6（免费有限 + Plus $20/月）

**核心定位：多模态+生态最全。**

| 最擅长 | 不太行 |
|--------|--------|
| ✅ 多模态——图片/文件/视频都能处理 | ❌ 中文写作有"机翻感" |
| ✅ DALL·E生图+Sora视频+Codex编程 | ❌ 免费版推理能力有限 |
| ✅ 生态最全：插件/GPTs/API/Agent | ❌ 免费用户高峰期限制严格 |
| ✅ GPT-5.6 Sol推理速度750 Token/秒 | ❌ 中文理解偶尔闹笑话 |
| ✅ 150万上下文+多Agent协作 | |

**最适合：需要多模态+生态集成的用户。** 如果你不仅聊天，还需要生图、做视频、用GPTs、接API——ChatGPT的生态目前没有竞品。

## 第三步：三套组合方案，直接抄作业

### 💰 方案一：零元党（全部免费，覆盖90%场景）

```
日常写作 + 泛问          → DeepSeek V4（网页版）
搜索 + 调研 + 读长文      → Kimi K2.5 Agent
写代码 + 微信小程序       → GLM-5.2（chat.z.ai）
验证事实 + 数据分析       → Google AI Studio（Grounding）
英文写作 + 复杂推理       → Claude 免费版（省着用）
```

**月费：$0。** 这套组合已经能覆盖绝大多数人的所有需求。唯一的不便：要在几个网页之间切换。

---

### ⚡ 方案二：效率优先（花$20/月，一个工具干80%的活）

```
主力（80%的任务）        → Claude Pro $20/月 或 ChatGPT Plus $20/月
中文写作                 → DeepSeek V4 免费版
写代码                   → GLM-5.2 免费版 + Claude
搜索 + 调研              → Kimi 免费版
```

**选Claude Pro的逻辑：** 你写的东西需要"人味"、需要深度推理。
**选ChatGPT Plus的逻辑：** 你需要多模态（生图/视频）、用GPTs生态。

**不要两个都买。** 先选一个用一个月，不够再换。

---

### 🚀 方案三：开发者/企业（API为主，成本可控）

```
高频推理（省钱）          → DeepSeek V4-Flash API（$0.14/M输入）
复杂代码 + Agent          → GLM-5.2 API（$1.40/M输入）或本地部署
私有化部署                → Qwen3.8-Max（权重下周开源后）+ 27B本地版
英文任务                  → Claude API（贵但稳）
多模态任务                → GPT-5.6 API
```

**成本估算：** 日均1万次推理 → DeepSeek V4-Flash约$1.4/天，GLM-5.2约$14/天，Claude约$31/天。**如果你能用V4-Flash替代70%的调用，月API账单可以从$1000降到$50。**

## 一个更重要的建议：不要同时追多个模型

选完一个主力模型，**用两周不换。** 每一天换一个新模型测试，你花在"比较工具"上的时间比"使用工具"还多——这是一种新型的拖延症。

**用模型的质量 << 用模型做出来的东西的质量。**

你用什么模型写作，读者看不出来。读者看得出来的是你的观点有没有价值。把省下来的"选模型"的时间，用来打磨内容。
