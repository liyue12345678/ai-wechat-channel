## 先说清楚：直播脚本和短视频脚本，完全是两码事

很多人以为"我写过短视频脚本，直播也能套"。**错了。** 两个最本质的区别：

1. **短视频是"录播"，可以反复改；直播是"现场"，没有NG。** 所以直播话术要"耐讲"——一个卖点要能翻来覆去讲三遍还不重样。
2. **短视频是"单向输出"，直播是"实时互动"。** 所以话术里必须留出"接话茬"的地方：欢迎新进直播间的人、回答弹幕提问、处理"太贵了"这种异议。

**这决定了直播脚本的结构和短视频完全不同。** 一个能用的直播脚本，至少要包含下面这几段：

```
开场钩子 → 留人（让刚进来的人别走）→ 痛点共鸣 → 产品亮相
→ 三维卖点拆解 → 价格锚定 → 限时动作指令 → 结尾互动引导
```

别慌，这套结构不用你背，**让AI帮你填就行。**

## 第一步：用AI生成整场直播脚本（附提示词）

把下面这段提示词复制进DeepSeek（或通义、Kimi），替换方括号里的内容：

```
你是一位资深的抖音/视频号直播带货操盘手，擅长写"留人+转化"的直播脚本。

请帮我写一场 [时长，如3小时] 的直播脚本，产品信息如下：
- 产品：[产品名，如一款女装连衣裙]
- 核心卖点：[卖点1、卖点2、卖点3，如显瘦版型、冰丝面料、79元]
- 目标人群：[人群描述]
- 价格：[原价 + 直播间价]
- 优惠：[满减/赠品/限时折扣]

要求：
1. 按"开场钩子→留人→痛点共鸣→产品亮相→三维卖点拆解→价格锚定→限时动作指令→结尾互动引导"的结构写
2. 每段给出"完整话术"，口语化，像主播在跟观众唠嗑，不是广告腔
3. 每段标注"这段的目的"和"建议讲多久"
4. 单独给出10句"欢迎话术"（新观众进直播间时用）
5. 单独给出5句"处理异议的话术"（针对"太贵了""再看看"）
```

AI会输出一套结构完整的脚本。**先别急着开播，这套是"初稿"，还得过第二步。**

---

## 第二步：拆成"模块化话术库"，关键是要"不重样"

直播最大的难点，是**同一个卖点要翻来覆去讲好几遍，还不能让观众觉得你在复读。**

解决方法：**让AI把每个卖点，用三种不同的话术写一遍。**

复制这段提示词：

```
把上面脚本里 [某个卖点，如"显瘦版型"] 的讲解，重写成3个版本：
- 版本1：理性讲解版（讲数据、讲版型原理）
- 版本2：情绪煽动版（讲穿上之后的场景和想象）
- 版本3：干货测评版（讲怎么挑、对比同类）

三个版本都是口语化话术，各150-200字，风格要明显不同。
```

**这一步的价值：你不是在"背稿子"，是在"储备弹药"。** 一场3小时的直播，你不可能每个字都照着念，但有了三套话术，任何时候都能从库里抽一句来讲，永远不会冷场。

## 第三步：生成"逼单话术"和"互动节奏"

直播的成交，靠的是最后那一下"逼单"。这一步，让AI专门写"促单"内容：

```
请帮我写直播的"逼单"话术，要求：
1. 价格锚定：先报原价 [原价]，再报直播间价 [直播间价]，强调"只有今天/只有现在"
2. 限时动作：给出明确的行动指令（"点下方链接""现在下单前50名送XX"）
3. 稀缺感：强调库存/时间限制
4. 写3个版本，语气从"温和"到"强促单"递进
```

**同时，让AI给你一张"互动节奏表"——每隔多久、说什么类型的话：**

| 时间点 | 动作 | 话术类型 |
|--------|------|---------|
| 开播前5分钟 | 暖场 | 唠家常、预告今晚福利 |
| 每15分钟 | 留人 | 报"现在进来的人有多少福利" |
| 每30分钟 | 逼单 | 报价格、限时、库存 |
| 有人提问时 | 接话 | 回答+顺势介绍产品 |
| 下播前10分钟 | 收尾 | 总结福利、引导关注 |

**有了这张表，你就不用再"盯着时间轴发慌"，照着节奏走就行。**

## 第四步：让AI直接"替你播"——数字人直播

如果你连出镜都不想，2026年还有个更省事的选择：**数字人直播。**

主流平台都能做到：**上传产品图 + 话术文本，AI生成一个数字人主播，24小时不间断播。** 比如：

- **腾讯云AIGC直播**：上传主播图片和话术，图文生直播，AI生成的话术支持4种风格——**带货、幽默、专业权威、温柔亲切**
- **百度智能云数字员工**：AI动态话术（每轮自动改写、不重样）、自动回答弹幕、真人随时接管
- **BytePlus Live**：24小时无人值守，脚本驱动控制节奏

**适合谁：不想露脸、想拉长直播时长的店主。** 但注意——**数字人直播目前更适合"标准化带货"（美妆、百货、本地生活券），强互动、强人设的品类，真人效果还是更好。**

## 进阶玩法：搭一个"话术生成助手"，一劳永逸

如果你想长期直播，与其每次手动写提示词，不如搭一个**专属话术助手**。方法很成熟：

1. **用Coze（扣子）搭一个"直播话术助手"智能体**：把工作流拆成4个模块——预热话术、置入话术、策略话术、销售转化话术，一次输入产品信息，一键输出万字脚本。
2. **用飞书OpenClaw整理现有话术**：如果你已经攒了一堆话术、又长又乱，丢给AI，3分钟整理成结构化SOP（脚本清洗→结构拆解→卖点提炼→脚本重写→SOP输出）。

**一句话：新手先用"提示词"起步，跑通了再搭"助手"，别一上来就搞复杂工作流。**

## 常见问题

**Q：AI写的话术，念起来很"AI腔"怎么办？**
A：正常，AI第一次写都偏书面。**两个办法：一是提示词里强调"口语化、像唠嗑"；二是把AI写的念一遍，把你觉得别扭的词换成你自己习惯的说法。** AI是"初稿生成器"，你负责"过一遍嘴"。念顺了，才是你的话术。

**Q：直播中观众问的问题，AI没提前写到怎么办？**
A：**直播中遇到突发提问，现场让AI答。** 把弹幕问题丢给DeepSeek（手机版也能用），它几秒钟给一段回复。所以开播时，把手机放在旁边开着AI对话框，就是你的"场外军师"。

**Q：数字人直播会被平台限流吗？**
A：各平台对"数字人直播"的政策在收紧，**建议数字人用于"拉时长"，关键成交时段还是真人上。** 也别用太假的数字人，容易被观众识破、影响信任。
