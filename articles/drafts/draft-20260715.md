## 二、全流程概览

写论文/报告分为6个阶段，AI在每个阶段扮演不同角色：

| 阶段 | AI的角色 | 你要做的事 |
|------|---------|-----------|
| 1. 选题 | 头脑风暴助手 | 确定方向 |
| 2. 文献 | 检索助理 + 摘要提取器 | 筛选+精读 |
| 3. 大纲 | 逻辑框架设计师 | 调整结构 |
| 4. 写作 | 段落生成器 + 草稿工具 | 把控核心观点 |
| 5. 润色 | 编辑 + 校对 | 最终审核 |
| 6. 格式 | 格式校验器 | 检查 |

**核心原则：AI出草稿，你来把关。** AI写的每一句话你都应该读过、理解过、认可以过。它不是代替你思考——是帮你把思考变成文字。

## 三、阶段一：选题（从"不知道写啥"到"有了明确方向"）

### 场景：导师说"你自己选个题吧"，然后你大脑一片空白。

**把这段提示词给AI：**

```
我是一名[大三/研二]学生，专业是[计算机科学/市场营销/教育学/你的专业]。

我现在需要为一篇[毕业论文/期末论文/研究报告]确定选题。

请帮我做以下事情：

1. 根据我的专业领域，列出10个当前值得研究的方向或热点话题。每个方向用一句话说明为什么值得研究。

2. 对每个方向，评估：
   - 资料获取难度（容易/中等/困难）
   - 研究空间（前人研究少/有改进空间/已很成熟）
   - 实操可行性（不用特殊数据/需要调查问卷/需要企业数据）

3. 从这10个方向中，选出3个最适合"本科生/硕士生独立完成"的，并给出具体的论文题目建议（每个方向2-3个备选题目）。

格式清晰，方便我直接复制去和导师讨论。
```

### AI会怎么帮你

它会给你一个有结构的选题清单。以"市场营销"专业为例，可能输出：
- "短视频平台的用户购买决策影响因素研究"（资料易获取，问卷可做）
- "AIGC对内容营销策略的影响——以小红书为例"（热点，但数据需爬取）
- 等等

**你的下一步：** 拿着AI给的3-5个候选选题，选你最感兴趣的那个，去和导师确认。不要自己拍板——选题这个环节，导师的经验比AI重要。

## 四、阶段二：文献综述（从"文献太多读不完"到"只读最相关的20篇"）

### 这一步最容易被"信息过载"压垮

一个研究方向可能有几百篇相关论文。全读不可能。AI在这一步的价值是：**帮你从200篇文献里筛出最值得读的20篇，再帮你快速理解每篇的核心内容。**

### 步骤1：找文献

用Kimi搜索或Perplexity：

```
我正在研究"[你的论文题目]"。

请帮我搜索相关的中文和英文学术文献。要求：

1. 列出15-20篇最相关、最有影响力的论文/期刊文章
2. 每篇包含：作者、发表年份、期刊/来源、核心研究问题、主要结论
3. 优先推荐：
   - 近5年的文献
   - 被引次数高的经典文章
   - 有方法创新的研究

4. 把这些文献按主题分成3-4个集群（比如：理论框架类、实证研究类、方法论类），方便我理解这个领域的研究图景。

请优先使用可公开访问的学术来源（知网、Google Scholar、arXiv、ResearchGate等）。
```

### 步骤2：快速理解每篇文献的要点

拿到文献列表后，你可以把单篇论文的摘要（或者论文的前言+结论部分）粘贴给AI，让它帮你快速提取要点：

```
以下是一篇学术论文的摘要和结论部分。请帮我提取：

1. 核心研究问题（一句话）
2. 研究方法（用了什么数据/方法/实验设计）
3. 最重要的发现（不超过3条）
4. 这篇文章对我的研究的参考价值（一句话）

[粘贴摘要和结论]
```

### 步骤3：写文献综述

积累了十几篇文献的要点后，让AI帮你组织：

```
根据以下文献要点，帮我撰写文献综述的第一稿。

要求：
- 按主题组织，不是按文章逐篇罗列
- 每段先说"已有研究发现了什么"，再说"还有什么没研究到"
- 最后总结"研究缺口"——这正是我这篇论文要填补的
- 学术化表达，但不要故作高深
- 标注引用位置（用[作者, 年份]标记）

[粘贴你整理的文献要点]
```

> ⚠️ **重要提醒**：AI可能会"编造"不存在的文献或引用。你必须在Google Scholar/知网上逐一核实AI提到的每一篇文献。AI可以帮你提速，但不能帮你做学术诚信的判断。**引用的每一篇文献，你必须自己确认它真实存在。**

## 五、阶段三：大纲（从"想法很散"到"有清晰骨架"）

有了选题和文献基础，下一步是搭骨架。这是整个论文最重要的环节——**大纲定好了，后面只是填空题。大纲没定好，写到一半会推翻重来。**

### 提示词：

```
基于以下信息，帮我设计论文大纲：

论文题目：[你的题目]
研究对象：[你要研究什么]
研究方法：[问卷/案例分析/实验/文献分析等]
预期篇幅：[8000字/15000字/30000字]

请按以下结构组织大纲：

第一章 绪论
- 研究背景（为什么这个问题值得研究）
- 研究意义（理论意义+实践意义）
- 研究方法概述
- 论文结构说明

第二章 文献综述与理论基础
- [填3-4个你从文献阶段整理出的主题]

第三章 研究设计/方法论
- [根据你的研究方法展开]

第四章 研究发现/数据分析
- [预计会有哪些主要发现，分点列出]

第五章 讨论
- [你的发现和已有研究的对话]
- [你的发现有什么实践启示]

第六章 结论
- 研究总结
- 研究局限
- 未来研究方向

每个章节下面再列2-3级子标题，越具体越好。我要看到论文的完整"骨架"。
```

**拿AI生成的大纲，做三件事：**
1. 调整章节顺序和标题措辞（改成你自己的语气）
2. 检查逻辑流（第一章的"研究问题"是否在第五章得到了回答？）
3. 拿这个大纲去和导师确认，不要闷头写到一半才发现方向不对

## 六、阶段四：写作（最容易被滥用的环节，也是最需要警惕的）

### ⚠️ 先看这一段，再看提示词

**AI在写作阶段能做和不能做的事：**

✅ **可以做的：**
- 帮你扩展大纲条目成段落初稿
- 帮你写"过渡句"（从一段到另一段的衔接）
- 帮你把你的观点转化成学术化的表达
- 帮你写方法论部分的"模板化"内容（如数据清洗步骤的描述）

❌ **不能做的（做了就是学术不端）：**
- 让它直接生成整篇论文然后交上去
- 不读、不理解、不修改AI生成的内容
- 使用AI生成的引用而不核实

**一个判断标准：如果你不愿意跟导师说"这部分是AI帮我写的"——那就不应该用AI写这部分。**

### 逐章节写作的提示词模板

**方法1：从大纲条目到段落**

```
把下面这条大纲条目扩展成[500-800字]的学术段落。

大纲条目：[粘贴你的大纲条目]

要求：
- 开门见山，第一句话就点明本段的论点
- 提供至少2个支撑论点的证据（来自文献或逻辑推理）
- 段落结尾，自然过渡到下一个话题
- 学术但不晦涩，专业术语需要解释
- 用中文写作，英文术语首次出现时括号标注原文

这只是初稿，我会在此基础上修改。
```

**方法2：写"难写"的部分——比如"研究意义"**

```
帮我写一段"[论文题目]"的研究意义部分（约400字）。

结构：
1. 先写理论意义：这个研究对现有理论有什么补充（填补了什么空白、验证了什么假设、提出了什么新框架）
2. 再写实践意义：这个研究的结论对从业者/政策制定者/教育者有什么具体帮助

结合以下背景信息：
[粘贴你的研究背景]

不要空喊口号（"具有重大意义"这种话少用），要具体说"对谁有意义、什么意义、为什么"。
```

**方法3：写文献综述的"批判性讨论"**

```
帮我改写下面的文献综述段落，加强"批判性"。

原文：
[粘贴你的段落]

改写的目标：
- 不只是说"XX研究了YY"——还要说"XX的研究在什么方面有局限/遗漏/争议"
- 把几篇文献联系起来讨论，而不是逐篇介绍
- 用"然而""但是""与之不同""一个尚未被充分探讨的问题是"这类转折词建立对话感

保持学术口吻，不要变得像小红书文案。
```

## 七、阶段五：润色（从"能看"到"能交"）

写完初稿后，从头到尾自己读一遍——这个过程不能偷懒。然后逐段丢给AI润色：

### 润色提示词（三段式）

**第一轮：学术化润色**

```
请帮我润色以下段落，使其更符合学术论文的表达规范。

要求：
- 消除口语化表达（"很多""挺""有点" → 学术化表达）
- 改善句子结构（过长/过短的句子调整到合适的长度）
- 统一术语（同一概念不要在全文用不同词）
- 保持原文的核心意思和论证逻辑不变
- 不要添加原文没有的观点或数据

原文：
[粘贴段落]
```

**第二轮：降重润色（如果你的学校查重）**

```
以下段落我用自己的话重新改写，请帮我检查是否还存在以下问题：
1. 和原文过于相似的结构或表达
2. 可以换一种表述方式的句子（提供2-3种替换选项）
3. 是否有更精炼的表达（废话太多的句子）

原文：
[粘贴段落]
```

**第三轮：一致性检查**

```
请检查以下两个段落之间的逻辑一致性：
段落A：[粘贴]
段落B：[粘贴]

检查：
1. 两段的论点有没有互相矛盾的地方
2. 术语和概念使用是否一致
3. 过渡是否自然

如果有问题，提出具体的修改建议。
```

## 八、阶段六：格式与参考文献（最容易被忽视的环节）

格式不对是论文被退回的最常见原因之一。这种事完全没必要自己手动调整——AI做这种事最擅长。

### 参考文献格式化

```
请将以下参考文献信息，按照[APA第7版/GB/T 7714/MLA]格式整理成完整的参考文献条目：

[粘贴你收集的文献信息：作者、年份、标题、期刊/出版社、卷期页码、DOI等]

如果信息不完整，标注出来提醒我补充。不是自己编造缺失的信息。
```

### 摘要优化

摘要是论文的"脸面"，很多审稿人/老师看摘要就决定了对论文的第一印象：

```
以下是我的论文摘要初稿。请帮我优化，使其更符合期刊论文摘要的标准：

摘要初稿：
[粘贴]

优化要求：
1. 结构完整：背景(1-2句) → 研究问题(1句) → 方法(1句) → 主要发现(2-3句) → 结论/启示(1句)
2. 总字数控制在[200-300字]
3. 每句话都要有信息量，删掉"本研究具有重要价值"这类废话
4. 让一个不了解这个领域的人读完也能明白我做了什么

给我三个版本：一个偏学术严谨、一个偏可读性、一个平衡型。
```

## 九、完整流程图 + 时间预估

```
整个流程按两周安排：

第1天：选题（AI辅助头脑风暴 + 与导师确认）           → 2h
第2-3天：文献检索与筛选（AI搜索 + 手动核实 + 精读）   → 8-10h
第4天：整理文献要点 + 撰写文献综述草稿                → 4h
第5天：生成大纲 + 与导师确认                         → 2h
第6-9天：逐章写作（每天一章，用AI辅助初稿）           → 每天2-3h
第10-11天：全文通读 + AI润色 + 降重                  → 6h
第12天：格式调整 + 参考文献整理 + 摘要优化            → 3h
第13天：最终通读 + 提交                               → 2h

总耗时：约30-35小时，分散在两周
```

> 💡 如果你只有一周时间——文献和写作阶段压缩并行，但润色阶段不能省。

## 十、一个重要提醒

这篇教程教的是"怎么用好AI这个工具来写出更好的论文"——不是"怎么让AI替你写"。

两者的区别在于：**你读了没有，你理解了没有，你能不能在答辩时/汇报时回答关于这篇论文的任何问题。**

如果你能——那AI就是一个极其强大的助手。它帮你度过了"面对空白文档不知道第一句写什么"的恐惧，帮你把散乱的思考组织成结构化的文字，帮你在格式和润色上省下了大把时间。

如果你不能——你会后悔的。老师/审稿人有无数种方法判断你是否真的理解了你提交的内容。

**把AI当一个24小时在线的学长/学姐。它可以给你建议、帮你改语法、给你指方向——但你得自己走到终点。**
