## 一、为什么写这篇？

我在"DeepSeek V4使用技巧"那篇里测了AI写公众号文章，写完之后收到好几个做小红书的朋友私信——"能不能测一下小红书？小红书的写法和公众号完全不一样。"

确实不一样。公众号是"看完"，小红书是"刷到"。公众号读者会给你3分钟，小红书用户给你3秒——前两行抓不住人就划走了。

小红书文案有自己的一套规则：标题要带数字和emoji、正文要分行不能大段文字、结尾要有互动引导、话题标签不能乱打。

**好消息是：AI不知道这些规则，但你可以告诉它。** 下面这套提示词就是把小红书的"潜规则"翻译成AI能执行的指令。

## 二、写之前先搞清：小红书文案和公众号文案的核心区别

| | 公众号 | 小红书 |
|------|--------|--------|
| **阅读场景** | 主动打开，有时间 | 刷信息流，碎片时间 |
| **耐心程度** | 3-5分钟 | 30秒-1分钟 |
| **文字密度** | 可以大段 | 每段不超过3行 |
| **标题作用** | 概括内容 | 制造好奇/焦虑/共鸣 |
| **关键位置** | 前300字 | **前18个字**（折叠线以上） |
| **emoji用法** | 少量或不用 | 标题和正文都要，分段必备 |
| **结尾** | 总结+预告 | 互动提问+话题标签 |

### 小红书正文黄金结构

```
标题（封面大字，1-2个emoji开头，15字以内）

正文开头（前18个字决定展开率——立刻说"你能得到什么"）

│ 分行写
│ 每段2-3句
│ 用emoji分段
│ 像在跟闺蜜分享

中间干货（用数字编号，1️⃣2️⃣3️⃣，清晰可扫读）

结尾：
- 互动引导（"你呢？"/"有没有同款？"/"评论区告诉我"）
- 话题标签 #  #  #
```

## 三、完整提示词（复制即用）

### 第一步：初始化AI的角色

```
你是一个小红书内容策划，服务账号信息如下：

- 账号赛道：[填：美妆/穿搭/家居/职场/数码/母婴/探店/其他]
- 账号风格：[填：干货型/人设型/种草型/测评型]
- 目标受众：[填：比如"25-35岁上班族女性，想变美但没时间研究"]
- 人设：[填：比如"3年大厂工作经验的产品经理，说话直不绕弯"]
- 参考博主：[填1-2个你喜欢的同赛道博主名字，让AI理解你要的调性]

确认你理解了这个账号的定位和风格后，回复"明白，开始吧"。
```

### 第二步：选题 + 标题

```
好的，帮我围绕[主题关键词，如：通勤穿搭/面试技巧/平价护肤品]出5个选题方向。

每个选题标注：
1. 选题角度（一句话）
2. 目标读者痛点（这篇解决什么问题）
3. 三个标题备选（要求：前15字包含核心关键词 + 带数字 + 有钩子 + 1-2个emoji）

标题要求：
- 不要太标题党（会被限流）
- 不要用"绝了""yyds""救命"这种过度的词
- 用"具体数字+具体场景+具体效果"替代夸张形容词

输出后让我挑选，我选好后再写正文。
```

### 第三步：正文撰写

选好标题后，继续：

```
好的，基于我选的标题，帮我写完整的正文。

格式要求：
✏️ 开头（关键！）：前18个字必须说清楚"这篇文章给你什么"。用真实场景引入，不要"今天给大家分享……"这种废话开头。

✏️ 中间干货：
- 用 1️⃣2️⃣3️⃣ 或 🌟✨📌 符号分行
- 每段不超过3行（手机上看超过3行就是一大坨）
- 每个要点先说结论再展开
- 加真实细节（具体数字、具体场景、具体品牌名），不要抽象描述

✏️ 结尾：
- 一句总结（可选，简短）
- 互动引导："你呢？[具体问题]" 或 "有没有[类似经历]的？评论区举手"
- 5-8个话题标签 #格式 #不要 #乱堆

风格要求：
- 像在跟闺蜜/朋友分享，不要像在写说明书
- "我"的使用频率高于"我们""
- 可以有口语化的感叹词，但控制在每段1个以内
- 不要用"绝绝子""yyds"等过度营销的词
- 整体真实感 > 精致感

字数：正文300-600字（小红书笔记最佳长度区间）
```

## 四、不同赛道，提示词微调

### 美妆/护肤类

在第二步提示词后追加：
```
这类内容容易被判广告，正文中：
- 不说"一定要买""必入"，改成"我自己用了XX的感受是……"
- 优缺点都说，增加可信度
- 加上自己的肤质/肤色（具体化人设）
```

### 职场/成长类

```
正文风格注意：
- 不要"教做人"的口吻，用"我自己踩过的坑"的方式写
- 每一条建议都要配一个真实场景（"比如有一次我……"）
- 禁止出现"努力就会成功"这种正确的废话
- 结论 > 过程 > 道理（先说结论再讲为什么）
```

### 穿搭/家居类

```
封面和关键词特别重要，正文中：
- 标注具体尺寸/价格/购买渠道（这些词是搜索高频词）
- 每件单品/物品单独一行，格式：🔗 [单品名]：[价格] [购买渠道]
- 描述用"视觉词"：颜色、材质、形状，不要只用"好看""高级"
```

### 探店/美食类

```
- 开头：店名+位置+人均（前18个字给完关键信息）
- 正文：按"推荐菜→环境→适合场景→排雷"的顺序
- 每道菜标注：必点/一般/踩雷，给明确判断
- 价格标注人均（具体数字，不要"不贵""很实惠"这种模糊词）
```

## 五、让AI帮你写封面文案

小红书封面上的文字和正文标题不一样——封面文字要更大、更短、更抓眼。

```
帮我基于刚才那篇笔记，出3个封面文案方案。

封面文案要求：
- 不超过10个字
- 大字排版友好（断句要自然）
- 可以是：痛点句（"穿了三年的通勤公式"）、数字句（"5件衣服=10套穿搭"）、反常识句（"越便宜的越好用"）

每个方案标注：适合配什么风格的封面图（实物拍照/文字海报/对比图/教程步骤图）
```

## 六、去AI味的最后一步

AI生成的初稿大概率带着一层"AI薄膜"——句子长度太均匀、语气一直平、没有任何人会用的奇怪措辞。

**拿到AI生成的正文后，做这5件事：**

1. **大声念一遍。** 念到不顺的地方直接用你自己会说的话替换。AI写了"该产品具有出色的保湿效果"→ 你改成"这个真的很润，我第二天上妆都不卡粉"。

2. **删掉所有"值得注意的是""综上所述""不可否认"。** 你没见过哪个小红书博主在笔记里用这些词。AI的默认学术腔会时不时漏出来。

3. **加一个只有你知道的细节。** AI可以写"这个粉底液遮瑕很好"，但你写"我下巴那颗痘印，用美妆蛋拍了两下就看不见了"——这才是读者停下来看的原因。

4. **检查数字是否真实。** AI可能会编造"我用了30天"——但你可能只用了3天。改成你真实的数字。

5. **把AI的"大家"改成"我"。** "大家可以去试试"→"我建议你先去专柜试一下色号"。第一人称是小红书笔记的灵魂。

## 七、常见问题

**Q: AI写的标题太标题党了怎么办？**
> 提示词里加一句："禁止使用'救命''绝了''天呐''我哭了''原地封神'等标题党高频词。"如果生成的标题还是太夸张，追加："再给5个更克制的版本。"

**Q: AI不会打emoji怎么办？**
> 在提示词里具体指定："每个要点前用emoji标注，比如：💰 价格、📍 地点、⚠️ 注意、✅ 推荐、❌ 踩雷。"不要只说"用emoji分段"，要告诉它用什么emoji。

**Q: 怎么让AI写的像我的个人风格？**
> 在初始化提示词里，把你写过的3-5条点赞最高的笔记正文直接贴进去，说"这是我之前写的笔记，请模仿这个风格和语气。"

**Q: AI生成的小红书内容会被检测出来吗？**
> 小红书目前没有明确说会检测AI生成内容。但读者能感觉到——AI味重的内容完播率低、互动少。所以最关键的不是"会不会被检测"，而是"读起来像不像真人"。上面的"去AI味五步法"比任何检测对抗都管用。

## 八、完整提示词懒人包

把以下内容一次性发给AI（按顺序填好方括号）：

```
你是一个小红书内容策划。我的账号信息：
- 赛道：[填]
- 风格：[填]
- 受众：[填]

请围绕[今天想写的主题]帮我做以下事：

1. 出5个选题方向，每个配3个标题备选（带emoji+数字，克制不标题党）
2. 我选好标题后，帮我写完整正文（300-600字，前18字给结论，emoji分段，结尾带互动引导和话题标签）
3. 基于正文出3个封面文案方案（10字以内）

风格：像跟朋友分享，有真实细节，不说"今天给大家分享"，不说"值得注意的是"。
```

## 九、最后的实话

小红书爆款的核心从来不是文笔。

是**选题的精准度**——你写的是不是1000个人正在搜的东西；
是**前18个字能不能让人停下来**——在信息流里和前后几十篇笔记抢注意力；
是**你有没有说只有你知道的事**——AI能写出"好用"，但写不出"我用了三周之后在下巴那颗痘印的位置发现"。

AI帮你解决的是"从空白页到有东西可改"这一程。从60分的初稿到90分的爆款——还是你的事。

而这个空间，恰恰是你作为一个"真人在分享"的价值所在。
