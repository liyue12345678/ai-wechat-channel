# 观点/分析文模板 — `opinion.md`

> 适用场景：行业大事件后输出观点，建立个人IP
> 预期阅读量：★★★★★（观点文最利于建IP，转发性强）
> 建议字数：1500-2500字
> 注意：观点文最忌"和稀泥"，必须有明确态度

---

## 标题公式

```
• XX发布了XX，但我有一个担忧
• 别再吹XX了，它有一个致命问题
• XX和XX必有一战，我看好XX的3个理由
• 我为什么看好/看衰XX？
• XX动了谁的蛋糕？—— 一文看懂XX事件
```

---

## 正文模板

### 第一段：事件 + 观点（200字）
```
[事件] 发生了。

很多人说XX，但我觉得XX。

一句话亮明观点：[加粗]

怎么得出这个结论的？往下看 ↓
```

### 第二段：背景补全（300字）
```
先花一分钟看看发生了什么：
- 时间线：X月X日 → X月X日
- 关键数字：XX亿参数 / XX亿美元 / XX万用户
- 利益相关方：A方 / B方 / C方

一句话说清楚利益关系：[谁动了谁的蛋糕]
```

### 第三段：你的核心论证（800-1000字）

选取一个角度深入，以下是3种经典框架：

#### 框架A：三论点式
```
论据1：[300字，数据/事实支撑]
论据2：[300字，案例/对比支撑]
论据3：[300字，逻辑推理]

综合以上：回到你的观点
```

#### 框架B：反面论证式
```
质疑1：有人说XX → 但事实是XX
质疑2：还有人说XX → 但数据显示XX
质疑3：可能有人担心XX → 实际上XX

所以，我的判断是XX
```

#### 框架C：类比式
```
这让我想起了[历史事件/其他行业案例]。

当时的情况是：[简述类比]

和今天的关系：[核心相似点]

从中我们可以学到：[你的洞察]
```

### 第四段：对读者的影响（200字）
```
所以，这对你意味着什么？

如果[你的观点正确]，那么：
- 作为普通用户，你应该XX
- 作为从业者，你需要XX
- 作为关注者，你可以XX
```

### 第五段：留尾巴（100字）
```
当然，我也可能错。如果XX发生，那就是另一回事。

你怎么看？评论区说说你的判断。
觉得有道理就转发，让更多人看到。
```

## 3个进阶技巧

### 1. 站在"反面"
```
当所有人都在说好的时候，你说"但我担心……"
当所有人都在唱衰的时候，你说"但我看到……"
→ 观点文的核心价值是提供不同视角
```

### 2. 用数据说话
```
不要只写"我觉得"，要写：
- "数据显示……"
- "我做了个实验……"
- "有X个案例表明……"
```

### 3. 承认局限
```
"当然，我也可能错" 这句话极其重要。
它降低了读者的防御心理，反而更容易被转发。
读者会说："这个作者挺客观的，转一下。"
```

---

## 避坑指南
- ❌ 不要只写情绪不写逻辑（"XX就是垃圾" ← 这是键盘侠，不是作者）
- ❌ 不要输出和所有人一样的观点（没有增量信息）
- ❌ 不要回避利益关系（如果收了钱就说收了钱）
- ✅ 观点要锋利，但论证要扎实
- ✅ 争议越大，转发越多，但别碰政治红线
