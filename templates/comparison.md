# 横向对比评测模板 — `comparison.md`

> 适用场景：多款AI工具/模型 做同一件事，横向对比
> 预期阅读量：★★★★★（对比类爆款率最高）
> 建议字数：2000-3000字

---

## 标题公式

```
• XX vs XX vs XX：谁才是最强的YY工具？
• 用同一道题考了5个AI，结果差距太大了
• 深度对比：XX、XX、XX 三款AI工具，到底选哪个？
• 花了3天实测6款XX工具，这篇文章帮你省时间
• XX刚更新，和XX比谁更强？实测结果出人意料
```

## 正文模板

### 第一段：一句话结论
```
[哪个工具/模型最强/最值，一句话说清楚]

比如：
"结论先行：如果你追求效果选ChatGPT，追求性价比选DeepSeek，追求生态选豆包。"
```

### 第二段：评测说明
```

- [工具A]（版本号）：[一句话介绍]
- [工具B]（版本号）：[一句话介绍]
- [工具C]（版本号）：[一句话介绍]

1. XX能力（权重40%）

4. 易用性（权重10%）

📌 评测方法：
[一句话说明怎么测]
```
