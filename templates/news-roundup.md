# AI资讯汇总模板 — `news-roundup.md`

> 适用场景：日更/周更资讯汇总，帮读者省时间
> 预期阅读量：★★★★（固定栏目，养成阅读习惯）
> 建议字数：1500-2500字
> 建议频率：每周日晚上发，帮读者做周度总结

---

## 标题公式

```
• AI周报｜XX发布XX，XX获得XX融资（第X期）
• 本周AI圈发生了什么？（202X.XX.XX - XX.XX）
• AI大事件｜[本周最大新闻] + [第二大新闻] + [第三大新闻]
• 别再被AI新闻淹没了，这X件事你需要知道
```

---

## 正文模板

### 固定开头（每期一样，建立识别度）
```
👋 这是「AI每周速览」第X期。
每周日晚上，帮你5分钟看完这周AI圈必须知道的新闻。

这周的关键词：[词1] · [词2] · [词3]
```

### 🌟 本周头条（1-2条，每条200-300字）

#### 事件1：[最重磅的新闻]
```
📌 发生了什么：
[2句话交代事件]

📌 为什么重要：
[2-3句话分析影响]

📌 和你的关系：
[1句话点明对普通用户/读者的影响]

🔗 延伸阅读：[链接]
```

#### 事件2：[第二重磅]
```
（同上结构）
```

### 🔥 其他值得关注的（3-5条，每条100字）
```
• [事件3]：[一句话事件] → [一句话解读]
• [事件4]：[一句话事件] → [一句话解读]
• [事件5]：[一句话事件] → [一句话解读]
```

### 💡 本周好用工具
```
这周发现的好工具/新功能：

1. [工具名] — [一句话干嘛的] — [免费/付费]
2. [工具名] — [一句话干嘛的] — [免费/付费]
```

### 📖 推荐文章
```
这周看到的深度好文：
- [文章标题](链接) — [一句话推荐理由]
- [文章标题](链接) — [一句话推荐理由]
```

### 下周关注
```
📅 下周值得关注的事件：
- X月X日：XX大会/发布
- 传闻XX可能发布XX功能

我们下周同一时间见👋
```
